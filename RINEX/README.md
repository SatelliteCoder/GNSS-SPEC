## 🌟 什么是 RINEX？

RINEX（Receiver Independent Exchange Format）是由瑞士伯尔尼大学天文研究所（AIUB）于 1989 年提出的 GNSS 数据交换格式，现已成为国际标准，由 IGS/RTCM RINEX 工作组维护。

**核心作用**：
- 实现不同品牌、不同型号接收机之间的数据交换
- 统一观测数据、导航电文、气象数据等的存储格式
- 便于科研、工程、测绘等领域的数据共享与处理

**支持的 GNSS 系统**：
- GPS（美国）
- GLONASS（俄罗斯）
- Galileo（欧盟）
- BDS / 北斗（中国）
- QZSS（日本）
- SBAS（星基增强系统）
- IRNSS / NavIC（印度）

## 📖 版本历史

### RINEX 2.x 系列

RINEX 2.x 是经典版本，被广泛应用于各种 GNSS 数据处理软件中。

| 版本 | 年份 | 主要更新 |
| :--- | :--- | :--- |
| 2.0 | 1999 | 基础版本，支持 GPS 和 GLONASS |
| 2.10 | 2007 | 增加 Galileo、SBAS、QZSS 支持 |
| **2.11** | 2012 | **2.x 最终版**，增加 L2C 观测码、GEO NAV MESS 等 |

**特点**：
- 文件格式紧凑，80 列文本格式
- 观测码为 2 字符（如 C1, P2, L1, L5）
- 站名 4 字符，年+年积日命名
- 仅支持有限的 GNSS 系统和信号类型

### RINEX 3.x 系列

RINEX 3.x 是重大升级版本，全面支持多星座、多频信号。

| 版本 | 年份 | 主要更新 |
| :--- | :--- | :--- |
| 3.00 | 2007 | 全新格式，3字符观测码，多系统支持 |
| 3.01 | 2009 | 增加 GLONASS 导航电文 |
| 3.02 | 2013 | 增加北斗、QZSS 支持 |
| 3.03 | 2015 | 扩展信号类型，增加 RINEX 时钟格式 |
| 3.04 | 2018 | 增加 BDS-3、IRNSS 支持 |
| **3.05** | 2020 | **3.x 最终版**，完善各系统信号定义 |

**特点**：
- 观测码扩展为 3 字符（如 C1C, L2W, C5X）
  - 第1位：观测类型（C=码伪距, L=载波相位, D=多普勒, S=载噪比）
  - 第2位：频率号（1=L1, 2=L2, 5=L5, 6=E6, 7=E5b, 8=E5a+b）
  - 第3位：通道/信号属性（C=C/A码, P=P码, W=无码, X=导频+数据等）
- 9 字符站名，支持更多元数据
- 全面支持 GPS, GLONASS, Galileo, BDS, QZSS, SBAS, IRNSS
- 文件头信息更丰富，增加了更多系统特定参数

### RINEX 4.x 系列

RINEX 4.x 是当前最新版本，在 3.x 基础上进一步扩展和优化。

| 版本 | 年份 | 主要更新 |
| :--- | :--- | :--- |
| **4.00** | 2021 | 首个 RINEX 4 版本，增强多系统支持 |
| 4.01 | 2023 | 修订与补充 |
| **4.02** | 2025 | **当前最新版**，完善信号定义与新系统支持 |

**特点**：
- 进一步扩展信号类型和系统支持
- 优化导航电文格式
- 更好地支持现代化信号（如 B1C, E1 OS, L1C 等）
- 与 RINEX 3.x 高度兼容，迁移成本低

## 🔍 各版本主要差异

| 特性 | RINEX 2.11 | RINEX 3.05 | RINEX 4.02 |
| :--- | :--- | :--- | :--- |
| **观测码长度** | 2字符 | 3字符 | 3字符 |
| **站名长度** | 4字符 | 9字符 | 9字符 |
| **支持系统数** | ~4个 | 7个+ | 7个+ |
| **GPS信号** | L1 C/A, L1 P, L2 P | L1 C/A, L1C, L2C, L5, P码 | 更全面 |
| **北斗支持** | 有限 | BDS-2 + BDS-3 | BDS-3 完整支持 |
| **文件命名** | 短名（8.3格式） | 长名（扩展命名） | 长名 |
| **导航电文** | 基础 | 分系统定义 | 更完善 |
| **当前状态** | 遗产兼容 | 广泛使用 | **最新标准** |
| **IGS 推荐** | 不推荐新数据 | 兼容支持 | **推荐使用** |

## 📂 RINEX 文件类型

RINEX 格式定义了多种文件类型，用文件扩展名区分：

| 扩展名 (2.x) | 扩展名 (3.x/4.x) | 文件类型 | 说明 |
| :--- | :--- | :--- | :--- |
| `.**o**` | `.obs` | 观测数据文件 | 伪距、载波相位、多普勒、载噪比等 |
| `.**n**` | `.nav` | GPS 导航电文 | GPS 广播星历 |
| `.**g**` | `.g` | GLONASS 导航电文 | GLONASS 广播星历 |
| `.**l**` | `.l` | Galileo 导航电文 | Galileo 广播星历 |
| - | `.b` | BDS 导航电文 | 北斗广播星历 |
| - | `.j` | QZSS 导航电文 | QZSS 广播星历 |
| - | `.i` | IRNSS 导航电文 | IRNSS 广播星历 |
| `.**m**` | - | 气象数据 | 温度、气压、湿度 |
| `.**clk**` | `.clk` | 钟差文件 | 卫星和测站钟差 |
| `.**sp3**` | `.sp3** | 精密星历 | 精密卫星轨道 |

## 📝 命名规则

### RINEX 2.x 命名

经典 8.3 格式命名：

```
SSSDDDD.YYT
│  │   │  ││
│  │   │  │└── T: 文件类型 (O=观测, N=GPS导航, G=GLONASS导航, M=气象...)
│  │   │  └─── YY: 年份后两位
│  │   └────── DDD: 年积日 (001-366)
│  └────────── SSSS: 测站名 (4字符)
```

**示例**：
- `ALGO1230.21O` — ALGO 站，2021 年第 123 天，观测文件
- `BRDC00IGS_R_20211230000_01D_MN.rnx` — (这是3.x格式，见下)

### RINEX 3.x / 4.x 命名

长命名格式（扩展命名）：

```
SSSSSSS_R_CCCC_YYYYDDDHHMM_DDD_TT_FN_FF
```

| 字段 | 长度 | 说明 |
| :--- | :--- | :--- |
| SSSSSSS | 9 | 测站名（不足用 0 填充） |
| R | 1 | 数据流：R=接收, S=流 |
| CCCC | 3-4 | 数据来源/格式标识 |
| YYYYDDDHHMM | 11 | 起始时间（年+年积日+时+分） |
| DDD | 3 | 文件周期（15M=15分, 01H=1小时, 01D=1天） |
| TT | 2 | 文件类型（MO=观测, MN=GPS导航等） |
| FN | 1-2 | 频率（_01S=单频, _02S=双频等） |
| FF | 3 | 文件格式（rnx=RINEX, crnx=压缩RINEX） |

**示例**：
- `ALGO00CAN_R_20211230000_01D_30S_MO.rnx`
  - ALGO 站（加拿大）
  - 起始时间：2021 年第 123 天 00:00
  - 时长：1 天，采样率 30 秒
  - 类型：观测文件 (Mixed Observation)
  - 格式：RINEX

## 🧭 如何选择版本？

| 使用场景 | 推荐版本 | 理由 |
| :--- | :--- | :--- |
| **新项目/新设备** | RINEX 4.02 | 最新标准，功能最全，面向未来 |
| **IGS 数据交换** | RINEX 3.05 或 4.x | IGS 已转向 RINEX 3/4 |
| **兼容老软件** | RINEX 2.11 | 很多老软件仅支持 2.11 |
| **北斗数据处理** | RINEX 3.05+ | 2.x 北斗支持不完善 |
| **多频多系统** | RINEX 3.05+ | 2.x 观测码不够用 |
| **教学/入门** | RINEX 2.11 | 格式简单，易于理解 |

**一般建议**：
- 新生成的数据使用 **RINEX 4.x** 格式
- 与旧系统交互时保留 **RINEX 2.11** 作为兼容格式
- 大多数现代 GNSS 软件（如 RTKLIB, GAMIT, Bernese）都同时支持 2.x 和 3.x/4.x
