## 🚀 概述

本文档详细介绍了在特定时间 `t` 下，计算 GNSS 卫星在地心地固 (ECEF) 坐标系中精确位置和速度的算法。该计算是 GNSS 信号仿真和定位解算的基础：

- **📡 信号仿真**：生成正确的码相位、多普勒频移和传播延迟
- **🧭 定位解算**：提供卫星位置的"地面真值"
- **🎯 高保真建模**：基于精确几何关系，计算大气延迟、多径等效应

计算将一组**开普勒轨道参数**和**摄动修正项**（由卫星导航电文广播）转换为三维直角坐标和速度矢量。

> 💡 **为什么需要摄动项？**
> 理想开普勒轨道假设地球是均匀球体，但实际地球是扁椭球，且受日月引力、太阳光压等影响，因此需要摄动修正项来提高精度。

## 📊 输入：广播星历参数

计算完全依赖于每颗卫星的**广播星历**数据集。一个典型的数据集包含 16 个参数。

| 参数名称 | 描述 | 符号 | 单位 |
| :--- | :--- | :--- | :--- |
| `sqrtA` | 轨道长半轴的平方根 | $\sqrt{A}$ | $\sqrt{m}$ |
| `e` | 轨道偏心率 | $e$ | 无量纲 |
| `i0` | 参考时刻的轨道倾角 | $i_0$ | 半圆 |
| `Omega0` | 参考时刻的升交点赤经 | $\Omega_0$ | 半圆 |
| `omega` | 近地点角距 | $\omega$ | 半圆 |
| `M0` | 参考时刻的平近点角 | $M_0$ | 半圆 |
| `Delta_n` | 平均运动角速度差 | $\Delta n$ | 半圆/秒 |
| `IDOT` | 轨道倾角变化率 | $\dot{i}$ | 半圆/秒 |
| `OmegaDot` | 升交点赤经变化率 | $\dot{\Omega}$ | 半圆/秒 |
| `Cuc`, `Cus` | 升交距角调和修正 | $C_{uc}$, $C_{us}$ | 弧度 |
| `Crc`, `Crs` | 轨道半径调和修正 | $C_{rc}$, $C_{rs}$ | 米 |
| `Cic`, `Cis` | 轨道倾角调和修正 | $C_{ic}$, $C_{is}$ | 弧度 |
| `toe` | 星历数据参考时间 | $t_{oe}$ | 秒 |
| `IODE` | 星历数据期龄 | - | - |

**🛑 关键提示：** 导航电文中的角度通常以**半圆**为单位。在三角函数中使用时，**必须**转换为弧度：`弧度 = 半圆 × π`。

## 📐 开普勒轨道基础

### 开普勒六参数

理想的开普勒椭圆轨道由6个参数完全确定：

| 参数 | 含义 | 决定 |
| :--- | :--- | :--- |
| **长半轴 a** | 轨道大小 | 轨道尺寸、平均运动角速度 |
| **偏心率 e** | 轨道扁率 | 轨道形状（圆/椭圆） |
| **轨道倾角 i** | 轨道面与赤道面夹角 | 轨道平面倾斜程度 |
| **升交点赤经 Ω** | 升交点在赤道上的位置 | 轨道平面方向 |
| **近地点角距 ω** | 近地点与升交点的夹角 | 椭圆在轨道面内的方向 |
| **平近点角 M** | 卫星在轨道上的位置 | 某一时刻卫星的位置 |

### 开普勒方程

开普勒方程是联系平近点角 M 和偏近点角 E 的核心方程：

$$
M = E - e \cdot \sin(E)
$$

其中：
- $M$：平近点角（随时间均匀变化）
- $E$：偏近点角（几何量）
- $e$：偏心率

**为什么重要？**
- 我们可以轻松计算任意时刻的平近点角 M
- 但需要偏近点角 E 来计算卫星在轨道上的位置
- 开普勒方程是超越方程，没有解析解，必须用迭代法求解

## ⚙️ 卫星位置计算步骤

以下步骤计算在所需的 GNSS 系统时间 `t`（例如 GPS 时）下的卫星位置。

### 步骤 1: 计算时间偏移量 `t_k`

首先，计算相对于星历参考时间 `t_oe` 的时间差。注意处理周内秒翻转。

```python
t_k = t - t_oe

# 如果 t_k 大于 302,400 秒（半周），减去 604,800
# 如果 t_k 小于 -302,400 秒，加上 604,800
if t_k > 302400:
    t_k -= 604800
elif t_k < -302400:
    t_k += 604800
```

**为什么要处理周翻转？**
GPS周内秒最大为604799秒（一周），如果t和t_oe分别在一周的两端（如t在周初，t_oe在周末），直接相减会得到错误的大值。

### 步骤 2: 计算校正后的平均角速度 `n`

计算理论平均角速度 `n0`，然后用星历中的 `Delta_n` 参数对其进行校正。

```python
GM = 3.9860050e14  # 地球引力常数 (m³/s²)
A = (sqrtA)**2     # 轨道长半轴 (m)
n0 = math.sqrt(GM / A**3) # 理论平均角速度 (rad/s)
n = n0 + Delta_n   # 校正后的平均角速度 (rad/s)
```

**物理意义**：
- $n_0$ 是根据开普勒第三定律计算的平均运动角速度
- $\Delta n$ 是修正项，考虑了地球非球形等摄动的影响

### 步骤 3: 计算平近点角 `M_k`

平近点角 `M_k` 在 `t_k` 时刻的值由参考值 `M0` 线性传播而来。

```python
M_k = M0 + n * t_k  # (rad)
```

平近点角随时间均匀增加，就像一个"平均"卫星以恒定角速度在圆轨道上运动。

### 步骤 4: 求解偏近点角 `E_k` (迭代法)

使用牛顿-拉弗森法求解开普勒方程 `M_k = E_k - e * sin(E_k)`。

```python
E_k = M_k  # 初始猜测值
delta_E = 1
max_iterations = 10
tolerance = 1e-12

for _ in range(max_iterations):
    delta_M = M_k - (E_k - e * math.sin(E_k))
    delta_E = delta_M / (1 - e * math.cos(E_k))
    E_k += delta_E
    if abs(delta_E) < tolerance:
        break
```

**收敛性**：
- 对于 GNSS 卫星（e很小，约0.01量级），通常2-3次迭代即可收敛
- 即使 e=0.5，也只需5-6次迭代
- 牛顿法的收敛速度是二次的

### 步骤 5: 计算真近点角 `ν_k`

根据偏近点角和偏心率计算真近点角。使用 `atan2` 函数以确保象限正确。

```python
sin_nu_k = (math.sqrt(1 - e**2) * math.sin(E_k)) / (1 - e * math.cos(E_k))
cos_nu_k = (math.cos(E_k) - e) / (1 - e * math.cos(E_k))
nu_k = math.atan2(sin_nu_k, cos_nu_k) # 真近点角 (rad)
```

**几何意义**：
真近点角是卫星在真实椭圆轨道上，从近地点算起的角度。

### 步骤 6: 计算升交距角 `Φ_k`

将真近点角与近地点角距相加。

```python
Phi_k = nu_k + omega # 升交距角 (rad)
```

升交距角是卫星从升交点算起的轨道角度。

### 步骤 7: 应用摄动修正

对升交距角、轨道半径和轨道倾角施加二阶谐波摄动修正。

```python
# 摄动修正量
delta_u_k = Cus * math.sin(2 * Phi_k) + Cuc * math.cos(2 * Phi_k)  # 升交距角修正
delta_r_k = Crs * math.sin(2 * Phi_k) + Crc * math.cos(2 * Phi_k)  # 轨道半径修正
delta_i_k = Cis * math.sin(2 * Phi_k) + Cic * math.cos(2 * Phi_k)  # 轨道倾角修正

# 应用修正
u_k = Phi_k + delta_u_k           # 修正后的升交距角
r_k = A * (1 - e * math.cos(E_k)) + delta_r_k  # 修正后的轨道半径
i_k = i0 + IDOT * t_k + delta_i_k  # 修正后的轨道倾角
```

**摄动来源**：
这些修正项主要考虑了地球非球形（J2项为主）引起的轨道摄动。角度以2Φ_k的形式出现，因为地球扁率的影响在轨道一圈内出现两次极大值。

### 步骤 8: 计算轨道平面内的位置

计算卫星在其轨道平面内的二维位置。

```python
x_k_prime = r_k * math.cos(u_k) # 在轨道平面内的 X 坐标
y_k_prime = r_k * math.sin(u_k) # 在轨道平面内的 Y 坐标
```

轨道平面坐标系：原点在地球中心，x轴指向升交点，y轴在轨道平面内垂直于x轴。

### 步骤 9: 转换到 ECEF 坐标系

通过考虑修正后的轨道倾角 `i_k` 和升交点赤经 `Omega_k`，将轨道平面内的坐标转换到 ECEF 坐标系。

```python
# 计算修正后的升交点赤经
OmegaDot_e = 7.2921151467e-5  # 地球自转角速度 (rad/s)
Omega_k = Omega0 + (OmegaDot - OmegaDot_e) * t_k - OmegaDot_e * t_oe

# 执行 3D 旋转（轨道平面 -> ECEF）
X = x_k_prime * math.cos(Omega_k) - y_k_prime * math.cos(i_k) * math.sin(Omega_k)
Y = x_k_prime * math.sin(Omega_k) + y_k_prime * math.cos(i_k) * math.cos(Omega_k)
Z = y_k_prime * math.sin(i_k)
```

**旋转过程说明**：
1. 绕z轴旋转 Ω_k（升交点赤经）
2. 绕x轴旋转 i_k（轨道倾角）
3. 最终得到ECEF坐标

**🎯 结果 `(X, Y, Z)` 即为时间 `t` 时卫星在 ECEF 坐标系中的位置。**

## 🧮 卫星速度计算

### 速度计算原理

卫星速度同样可以从星历参数计算得到。基本思路是对位置公式求导。

**核心公式**：

1. **偏近点角变化率**：
   $$
   \dot{E} = \frac{n}{1 - e \cos(E)}
   $$

2. **真近点角变化率**：
   $$
   \dot{\nu} = \frac{\sqrt{1 - e^2} \cdot n}{1 - e \cos(E)} = \frac{h}{r^2}
   $$
   其中 $h = \sqrt{GM \cdot a (1 - e^2)}$ 为角动量。

3. **轨道平面内速度**：
   $$
   \dot{x}' = -r \cdot \dot{u} \cdot \sin(u) + \dot{r} \cdot \cos(u)
   $$
   $$
   \dot{y}' = r \cdot \dot{u} \cdot \cos(u) + \dot{r} \cdot \sin(u)
   $$

4. **转换到ECEF**：对位置的旋转变换求导，注意地球自转的影响。

### 完整推导步骤

```python
def compute_satellite_velocity(eph, E_k, u_k, r_k, i_k, Omega_k, t_k):
    """
    计算卫星速度（简化版）
    
    完整的速度计算需要考虑摄动项对时间的导数，
    对于大多数应用，使用简化版（忽略摄动项的导数）足够精确。
    """
    # 基本参数
    GM = 3.9860050e14
    OmegaDot_e = 7.2921151467e-5
    
    A = eph['sqrtA'] ** 2
    e = eph['e']
    n = math.sqrt(GM / A**3) + eph['Delta_n']
    
    # 1. 偏近点角变化率
    Edot = n / (1 - e * math.cos(E_k))
    
    # 2. 轨道半径变化率
    rdot = A * e * math.sin(E_k) * Edot  # 简化，未包含摄动项
    
    # 3. 升交距角变化率（近似）
    # 真近点角变化率
    nudot = math.sqrt(1 - e**2) * n / (1 - e * math.cos(E_k))
    # 加上摄动项的变化率（可忽略的二阶小量）
    udot = nudot  # 简化
    
    # 4. 轨道平面内速度
    vx_prime = rdot * math.cos(u_k) - r_k * udot * math.sin(u_k)
    vy_prime = rdot * math.sin(u_k) + r_k * udot * math.cos(u_k)
    
    # 5. 转换到ECEF
    sin_Omega = math.sin(Omega_k)
    cos_Omega = math.cos(Omega_k)
    cos_i = math.cos(i_k)
    sin_i = math.sin(i_k)
    
    # 升交点赤经变化率
    Omega_dot = eph['OmegaDot'] - OmegaDot_e
    
    # 速度的ECEF分量（考虑坐标系旋转）
    Vx = (vx_prime * cos_Omega 
          - vy_prime * cos_i * sin_Omega
          - Omega_dot * (x_k_prime * sin_Omega + y_k_prime * cos_i * cos_Omega))
    
    Vy = (vx_prime * sin_Omega 
          + vy_prime * cos_i * cos_Omega
          + Omega_dot * (x_k_prime * cos_Omega - y_k_prime * cos_i * sin_Omega))
    
    Vz = vy_prime * sin_i
    
    return Vx, Vy, Vz
```

> ⚠️ **注意**：上述速度计算是简化版本。完整计算需要考虑摄动项的导数（δu、δr、δi随时间的变化率），但对于大多数应用（如多普勒计算），简化版的精度足够（误差在mm/s量级）。

## 🌍 坐标系与转换

### ECEF坐标系

**地心地固坐标系（Earth-Centered, Earth-Fixed）**：
- 原点：地球质心
- X轴：指向本初子午线与赤道的交点
- Y轴：指向东经90°与赤道的交点
- Z轴：指向北极（与地球自转轴重合）
- 随地球一起旋转

这是GNSS计算中最常用的坐标系。

### 大地坐标系（经纬高）

**大地坐标系（Geodetic Coordinate System）**：
- 纬度 φ：该点的法线与赤道面的夹角（-90° ~ +90°）
- 经度 λ：该点子午面与本初子午面的夹角（-180° ~ +180°）
- 大地高 h：该点沿法线到参考椭球面的距离

参考椭球（WGS-84）参数：
| 参数 | 值 |
| :--- | :--- |
| 长半轴 a | 6378137.0 m |
| 扁率 f | 1/298.257223563 |
| 第一偏心率 e² | 0.00669437999014 |

### 站心坐标系（ENU）

**站心坐标系（East-North-Up）**：
- 原点：测站位置
- E轴（东）：指向当地正东方向
- N轴（北）：指向当地正北方向
- U轴（天）：指向当地天顶方向

常用于表示相对位置、速度和精度因子（DOP）。

### 坐标转换公式

**ECEF → 大地坐标（迭代法）**：

```python
def ecef_to_geodetic(x, y, z, max_iter=10):
    """ECEF转大地坐标（WGS-84）"""
    a = 6378137.0
    e2 = 0.00669437999014
    
    p = math.sqrt(x*x + y*y)
    lon = math.atan2(y, x)
    
    # 初始估计
    lat = math.atan2(z, p)
    
    for _ in range(max_iter):
        sin_lat = math.sin(lat)
        N = a / math.sqrt(1 - e2 * sin_lat * sin_lat)
        h = p / math.cos(lat) - N
        lat = math.atan2(z, p * (1 - e2 * N / (N + h)))
    
    return math.degrees(lat), math.degrees(lon), h
```

**ECEF → ENU**：

```python
def ecef_to_enu(x, y, z, x0, y0, z0):
    """ECEF坐标转换为站心ENU坐标"""
    lat0, lon0, _ = ecef_to_geodetic(x0, y0, z0)
    lat0 = math.radians(lat0)
    lon0 = math.radians(lon0)
    
    dx = x - x0
    dy = y - y0
    dz = z - z0
    
    sin_lat = math.sin(lat0)
    cos_lat = math.cos(lat0)
    sin_lon = math.sin(lon0)
    cos_lon = math.cos(lon0)
    
    # 旋转矩阵
    e = -sin_lon * dx + cos_lon * dy
    n = -sin_lat * cos_lon * dx - sin_lat * sin_lon * dy + cos_lat * dz
    u = cos_lat * cos_lon * dx + cos_lat * sin_lon * dy + sin_lat * dz
    
    return e, n, u
```

## 📚 历书（Almanac）计算

### 历书与星历的区别

| 特性 | 星历（Ephemeris） | 历书（Almanac） |
| :--- | :--- | :--- |
| **精度** | 高（米级） | 低（公里级） |
| **有效期** | 短（2-4小时） | 长（数天到数周） |
| **参数数量** | 多（16+个） | 少（约8个） |
| **更新频率** | 每2小时更新 | 每天更新一次 |
| **用途** | 精确定位 | 快速捕获、卫星可见性预报 |

### 历书参数计算

GPS历书包含以下简化的轨道参数：
- 偏心率 e
- 长半轴的平方根 sqrt(A)
- 参考时刻的轨道倾角 i₀（相对于参考值的偏差）
- 升交点赤经速率 Ω_dot
- 升交点赤经在周开始时的值 Ω₀
- 近地点角距 ω
- 平近点角 M₀
- 参考时间 t_oa

历书计算步骤与星历类似，但：
- 没有摄动修正项（Cuc, Cus, Crc, Crs, Cic, Cis）
- 没有倾角变化率 IDOT（使用参考倾角）
- 精度较低，仅用于捕获和可见性预测

## 🧪 代码示例 (Python)

```python
import math

# 物理常数
GM = 3.9860050e14       # 地球引力常数 (m³/s²)
OMEGA_DOT_E = 7.2921151467e-5  # 地球自转角速度 (rad/s)
C = 299792458.0        # 光速 (m/s)


def semi_circle_to_rad(value):
    """半圆转弧度"""
    return value * math.pi


def compute_sat_pos(ephemeris, t):
    """
    根据广播星历计算卫星ECEF位置
    
    参数:
        ephemeris: 包含所有广播星历参数的字典（角度需已转为弧度）
        t: GPS周内秒 (s)
    
    返回:
        (X, Y, Z): ECEF坐标 (m)
    """
    # 提取参数
    sqrtA = ephemeris['sqrtA']
    e = ephemeris['e']
    M0 = ephemeris['M0']
    Omega0 = ephemeris['Omega0']
    i0 = ephemeris['i0']
    omega = ephemeris['omega']
    Delta_n = ephemeris['Delta_n']
    IDOT = ephemeris['IDOT']
    OmegaDot = ephemeris['OmegaDot']
    Cuc = ephemeris['Cuc']
    Cus = ephemeris['Cus']
    Crc = ephemeris['Crc']
    Crs = ephemeris['Crs']
    Cic = ephemeris['Cic']
    Cis = ephemeris['Cis']
    toe = ephemeris['toe']
    
    # --- 步骤 1: 时间偏移 ---
    t_k = t - toe
    if t_k > 302400:
        t_k -= 604800
    elif t_k < -302400:
        t_k += 604800
    
    # --- 步骤 2: 平均角速度 ---
    A = sqrtA ** 2
    n0 = math.sqrt(GM / A**3)
    n = n0 + Delta_n
    
    # --- 步骤 3: 平近点角 ---
    M_k = M0 + n * t_k
    
    # --- 步骤 4: 求解偏近点角 ---
    E_k = M_k
    for _ in range(10):
        delta_E = (M_k - (E_k - e * math.sin(E_k))) / (1 - e * math.cos(E_k))
        E_k += delta_E
        if abs(delta_E) < 1e-12:
            break
    
    # --- 步骤 5: 真近点角 ---
    sin_nu = (math.sqrt(1 - e**2) * math.sin(E_k)) / (1 - e * math.cos(E_k))
    cos_nu = (math.cos(E_k) - e) / (1 - e * math.cos(E_k))
    nu_k = math.atan2(sin_nu, cos_nu)
    
    # --- 步骤 6: 升交距角 ---
    Phi_k = nu_k + omega
    
    # --- 步骤 7: 摄动修正 ---
    delta_u = Cus * math.sin(2*Phi_k) + Cuc * math.cos(2*Phi_k)
    delta_r = Crs * math.sin(2*Phi_k) + Crc * math.cos(2*Phi_k)
    delta_i = Cis * math.sin(2*Phi_k) + Cic * math.cos(2*Phi_k)
    
    u_k = Phi_k + delta_u
    r_k = A * (1 - e * math.cos(E_k)) + delta_r
    i_k = i0 + IDOT * t_k + delta_i
    
    # --- 步骤 8: 轨道平面位置 ---
    x_prime = r_k * math.cos(u_k)
    y_prime = r_k * math.sin(u_k)
    
    # --- 步骤 9: ECEF坐标 ---
    Omega_k = Omega0 + (OmegaDot - OMEGA_DOT_E) * t_k - OMEGA_DOT_E * toe
    
    X = x_prime * math.cos(Omega_k) - y_prime * math.cos(i_k) * math.sin(Omega_k)
    Y = x_prime * math.sin(Omega_k) + y_prime * math.cos(i_k) * math.cos(Omega_k)
    Z = y_prime * math.sin(i_k)
    
    return X, Y, Z


def compute_sat_velocity(ephemeris, t):
    """
    计算卫星速度（简化但足够精确的版本）
    
    返回:
        (Vx, Vy, Vz): ECEF速度 (m/s)
    """
    # 先计算位置（需要E等中间变量）
    sqrtA = ephemeris['sqrtA']
    e = ephemeris['e']
    M0 = ephemeris['M0']
    Omega0 = ephemeris['Omega0']
    i0 = ephemeris['i0']
    omega = ephemeris['omega']
    Delta_n = ephemeris['Delta_n']
    IDOT = ephemeris['IDOT']
    OmegaDot = ephemeris['OmegaDot']
    toe = ephemeris['toe']
    
    # 重复位置计算的步骤（获取中间量）
    t_k = t - toe
    if t_k > 302400: t_k -= 604800
    elif t_k < -302400: t_k += 604800
    
    A = sqrtA ** 2
    n0 = math.sqrt(GM / A**3)
    n = n0 + Delta_n
    M_k = M0 + n * t_k
    
    E_k = M_k
    for _ in range(10):
        dE = (M_k - (E_k - e * math.sin(E_k))) / (1 - e * math.cos(E_k))
        E_k += dE
        if abs(dE) < 1e-12: break
    
    sin_nu = math.sqrt(1-e**2) * math.sin(E_k) / (1 - e*math.cos(E_k))
    cos_nu = (math.cos(E_k) - e) / (1 - e*math.cos(E_k))
    nu_k = math.atan2(sin_nu, cos_nu)
    
    Phi_k = nu_k + omega
    
    # 摄动（简化计算，速度计算中忽略摄动项的导数）
    delta_u = ephemeris['Cus'] * math.sin(2*Phi_k) + ephemeris['Cuc'] * math.cos(2*Phi_k)
    delta_r = ephemeris['Crs'] * math.sin(2*Phi_k) + ephemeris['Crc'] * math.cos(2*Phi_k)
    delta_i = ephemeris['Cis'] * math.sin(2*Phi_k) + ephemeris['Cic'] * math.cos(2*Phi_k)
    
    u_k = Phi_k + delta_u
    r_k = A * (1 - e*math.cos(E_k)) + delta_r
    i_k = i0 + IDOT * t_k + delta_i
    
    Omega_k = Omega0 + (OmegaDot - OMEGA_DOT_E) * t_k - OMEGA_DOT_E * toe
    
    x_prime = r_k * math.cos(u_k)
    y_prime = r_k * math.sin(u_k)
    
    # ---- 速度计算 ----
    
    # 偏近点角变化率
    Edot = n / (1 - e * math.cos(E_k))
    
    # 轨道半径变化率（简化，含摄动）
    rdot = A * e * math.sin(E_k) * Edot + 2 * (ephemeris['Crs']*math.cos(2*Phi_k) - ephemeris['Crc']*math.sin(2*Phi_k)) * nudot
    
    # 升交距角变化率
    nudot = math.sqrt(1 - e**2) * n / (1 - e * math.cos(E_k))
    udot = nudot + 2 * (ephemeris['Cus']*math.cos(2*Phi_k) - ephemeris['Cuc']*math.sin(2*Phi_k)) * nudot
    
    # 轨道平面内速度
    vx_p = rdot * math.cos(u_k) - r_k * udot * math.sin(u_k)
    vy_p = rdot * math.sin(u_k) + r_k * udot * math.cos(u_k)
    
    # 倾角变化率
    idot = IDOT + 2 * (ephemeris['Cis']*math.cos(2*Phi_k) - ephemeris['Cic']*math.sin(2*Phi_k)) * nudot
    
    # 升交点赤经变化率
    Omega_dot = OmegaDot - OMEGA_DOT_E
    
    # 转换到ECEF
    sin_O = math.sin(Omega_k)
    cos_O = math.cos(Omega_k)
    sin_i = math.sin(i_k)
    cos_i = math.cos(i_k)
    
    Vx = (vx_p * cos_O - vy_p * cos_i * sin_O 
          - Omega_dot * (x_prime * sin_O + y_prime * cos_i * cos_O))
    
    Vy = (vx_p * sin_O + vy_p * cos_i * cos_O 
          + Omega_dot * (x_prime * cos_O - y_prime * cos_i * sin_O))
    
    Vz = vy_p * sin_i + y_prime * cos_i * idot
    
    return Vx, Vy, Vz


# 使用示例
if __name__ == "__main__":
    # 示例星历参数（简化的典型值）
    eph = {
        'sqrtA': math.sqrt(26559710.0),  # 约26560km（MEO轨道）
        'e': 0.005,
        'M0': semi_circle_to_rad(0.1),
        'Omega0': semi_circle_to_rad(0.3),
        'i0': semi_circle_to_rad(0.29),  # 约55度倾角
        'omega': semi_circle_to_rad(0.5),
        'Delta_n': semi_circle_to_rad(0.0) / 1e9,
        'IDOT': semi_circle_to_rad(0.0) / 1e9,
        'OmegaDot': semi_circle_to_rad(-0.0001),
        'Cuc': 0.0, 'Cus': 0.0,
        'Crc': 0.0, 'Crs': 0.0,
        'Cic': 0.0, 'Cis': 0.0,
        'toe': 0.0
    }
    
    # 计算t=0时刻的位置和速度
    t = 0.0
    X, Y, Z = compute_sat_pos(eph, t)
    Vx, Vy, Vz = compute_sat_velocity(eph, t)
    
    print(f"卫星位置 (ECEF): ({X:.3f}, {Y:.3f}, {Z:.3f}) m")
    print(f"卫星速度 (ECEF): ({Vx:.3f}, {Vy:.3f}, {Vz:.3f}) m/s")
    print(f"轨道半径: {math.sqrt(X*X+Y*Y+Z*Z):.1f} m")
    print(f"速度大小: {math.sqrt(Vx*Vx+Vy*Vy+Vz*Vz):.1f} m/s")
```

## ⚠️ 重要注意事项

1. **🗓️ 周内秒翻转（WNRO）**：始终检查 `t_k` 是否需要通过 ± 604800 秒进行调整，确保其在与参考时间相差一周的范围内。

2. **🧮 单位转换**：最常见的错误来源。**确保导航电文中的所有角度参数都已从半圆转换为弧度。**

3. **⏰ 星历有效性**：广播星历有效期通常为 `t_oe` 前后 2-4 小时。超出此窗口精度会迅速下降。

4. **🎯 精度**：基于广播星历的位置精度约 **1-2 m (RMS)**。更高精度需使用精密星历（SP3文件，厘米级）。

5. **🔄 地球自转修正（Sagnac效应）**：计算得到的位置在**信号发射时刻** `t_{sv}` 有效。对于高精度应用，需考虑信号传播过程中地球自转的影响。

6. **📐 卫星速度**：大多数应用只需要卫星位置，速度用于多普勒计算。简化算法通常足够。

7. **📊 历书 vs 星历**：不要用历书做精确计算！历书精度只有公里级，仅用于捕获辅助和可见性预测。

8. **🌐 IODC/IOD一致性**：使用星历和钟差参数时，确保IODC（时钟数据期龄）和IODE（星历数据期龄）一致。
