## 🎯 概述

**多径效应（Multipath）** 是指GNSS信号在到达接收机天线之前，经过周围物体（建筑物、地面、水面等）反射，产生一个或多个延迟副本，与直射信号叠加产生干涉的现象。

多径效应是GNSS定位中的重要误差源之一：
- **伪距误差**：可达 10-100 米（极端情况下更大）
- **载波相位误差**：可达 1/4 波长（约5cm for L1）
- 是城市环境中定位精度下降的主要原因
- 难以通过差分技术消除（因为与环境高度相关）

## 📐 多径效应基本原理

### 多径信号模型

接收机接收到的信号是直射信号和多个反射信号的叠加：

$$
r(t) = A_0 \cdot C(t - \tau_0) \cdot D(t - \tau_0) \cdot \cos(2\pi f_c t + \phi_0) + \sum_{i=1}^{N} A_i \cdot C(t - \tau_i) \cdot D(t - \tau_i) \cdot \cos(2\pi f_c t + \phi_i) + n(t)
$$

其中：
- $A_0, \tau_0, \phi_0$：直射信号的幅度、延迟、相位
- $A_i, \tau_i, \phi_i$：第 $i$ 条多径信号的幅度、延迟、相位
- $N$：多径信号数量
- $n(t)$：噪声

### 多径对相关函数的影响

接收机通过相关运算进行码跟踪。当存在多径时，相关函数不再是理想的三角形，而是发生畸变。

**单反射多径模型**：

$$
R_{total}(\delta) = R(\delta) + \alpha \cdot R(\delta - \Delta\tau)
$$

其中：
- $R(\delta)$：直射信号的自相关函数
- $\alpha = A_1 / A_0$：多径与直射的幅度比（通常 < 1）
- $\Delta\tau = \tau_1 - \tau_0$：多径相对延迟（码片）

**关键影响**：
1. **相关峰畸变**：相关峰形状改变，可能出现多个峰值
2. **码跟踪偏差**：延迟锁定环（DLL）锁定点偏移
3. **载波相位偏差**：相位锁定环（PLL）锁定相位偏移
4. **信噪比下降**：多径信号与直射信号干涉，导致有效信噪比降低

## 📊 多径误差特性

### 码跟踪误差

对于标准的早-迟延迟锁定环（DLL），多径引起的码跟踪误差可表示为：

$$
\delta\tau_{mp} = \frac{\alpha \cdot \Delta\tau \cdot (1 - \frac{|\Delta\tau|}{T_c})}{2 + 2\alpha \cdot (1 - \frac{|\Delta\tau|}{T_c}) \cdot \cos(\Delta\phi)}, \quad |\Delta\tau| < T_c
$$

其中：
- $T_c$：码片宽度
- $\Delta\phi$：多径与直射信号的相位差

**重要特性**：
1. **短延迟多径（Δτ < 1码片）**：误差最大，难以抑制
2. **长延迟多径（Δτ > 1码片）**：误差较小，窄相关器可有效抑制
3. **误差范围**：±0.5 码片（对于BPSK信号）
4. **与信号带宽成反比**：带宽越宽，码片越窄，多径误差越小

### 载波相位误差

多径引起的载波相位误差：

$$
\delta\phi_{mp} = \arctan\left( \frac{\alpha \sin(\Delta\phi)}{1 + \alpha \cos(\Delta\phi)} \right)
$$

**特性**：
- 最大误差约为 $\arcsin(\alpha)$
- 当 $\alpha = 1$（多径幅度与直射相同）时，最大误差为 90°（1/4 波长）
- 载波相位多径误差通常远小于码多径误差

## 🏗️ 多径环境建模

### 反射面模型

#### 反射系数

信号从介质表面反射时，反射系数由菲涅尔公式描述：

**垂直极化（V极化）**：

$$
\Gamma_V = \frac{\varepsilon_r \sin\theta - \sqrt{\varepsilon_r - \cos^2\theta}}{\varepsilon_r \sin\theta + \sqrt{\varepsilon_r - \cos^2\theta}}
$$

**水平极化（H极化）**：

$$
\Gamma_H = \frac{\sin\theta - \sqrt{\varepsilon_r - \cos^2\theta}}{\sin\theta + \sqrt{\varepsilon_r - \cos^2\theta}}
$$

其中：
- $\varepsilon_r$：相对介电常数
- $\theta$：入射角（与法线的夹角）

GNSS信号为右旋圆极化（RHCP），反射后会变为椭圆极化。

#### 常见介质参数

| 介质 | 相对介电常数 $\varepsilon_r$ | 电导率 $\sigma$ (S/m) | 反射损耗 |
| :--- | :--- | :--- | :--- |
| **干燥地面** | 3 - 5 | 10⁻⁴ - 10⁻² | 中等 |
| **湿润地面** | 10 - 30 | 10⁻² - 1 | 较低 |
| **淡水** | 80 | 10⁻³ | 低 |
| **海水** | 80 | 3 - 5 | 很低 |
| **混凝土** | 5 - 10 | 10⁻² - 1 | 中等 |
| **金属** | ∞ | ∞ | 0 dB（全反射） |

### 镜面反射 vs 漫反射

| 类型 | 特点 | 适用场景 |
| :--- | :--- | :--- |
| **镜面反射** | 反射角等于入射角，相干 | 光滑表面（水面、玻璃、金属） |
| **漫反射** | 反射信号向各个方向散射 | 粗糙表面（地面、墙面） |

在仿真中，通常以镜面反射为主，叠加漫反射分量。

### 多径数量与分布

多径信号的数量和特性与环境密切相关：

- **开阔环境**：0-2条多径，主要来自地面反射
- **郊区环境**：2-5条多径
- **城市环境**：5-20条多径，延迟分布范围大
- **室内环境**：大量多径，严重时无直射信号（NLOS）

## 📡 典型多径场景

### 城市峡谷

在城市高楼之间，信号被建筑物多次反射：

**特点**：
- 大量多径信号（10-20条以上）
- 延迟扩展大（可达数百米）
- 直射信号可能被遮挡（NLOS）
- 信号强度快速衰落

**建模方法**：
- 基于3D城市模型的射线追踪
- 统计模型（Saleh-Valenzuela模型）
- 几何建模（虚拟源方法）

### 室内环境

室内多径更加复杂：

**特点**：
- 墙壁、天花板、地面多次反射
- 延迟扩展相对较小（几十纳秒）
- 多径数量极多（密集多径）
- 信号衰减大

### 海面反射

海面是强反射体：

**特点**：
- 海面反射信号强（反射系数接近1）
- 海面波动导致多径参数时变
- 低仰角时影响显著
- 对舰船和机载接收机影响大

### 地面反射

最常见的多径来源：

**特点**：
- 单条或少量多径
- 延迟较小（取决于天线高度）
- 反射损耗中等
- 天线低仰角时影响大

地面反射延迟近似公式：

$$
\Delta\tau \approx \frac{2 h \sin(E)}{c}
$$

其中 $h$ 为天线高度，$E$ 为仰角。

## 🧪 多径抑制技术

### 1. 窄相关器（Narrow Correlator）

- 减小早-迟相关器间距（如0.1码片）
- 可抑制长延迟多径（>0.5码片）
- 实现简单，广泛使用

### 2. 多径消除技术（MEDLL）

- 估计并消除多条多径信号
- 基于最大似然估计
- 性能好但计算量大

### 3. 高分辨率相关器

- 使用更多相关采样点
- 更精确地重构相关函数
- 如Strobe相关器、Double-Delta等

### 4. 特殊天线设计

- 扼流圈天线（Choke Ring Antenna）
- 抑制低仰角的地面反射
- 可降低多径误差50%以上

### 5. 信号设计

- 更大的信号带宽（更窄的相关峰）
- BOC调制（更尖锐的相关特性）
- 如GPS L5、Galileo E5a

## 💻 代码实现示例

### Python 多径信号仿真

```python
import numpy as np
import matplotlib.pyplot as plt


def generate_prn_code(code_length=1023, seed=1):
    """生成伪随机码序列（简化版）"""
    np.random.seed(seed)
    return np.random.choice([-1, 1], size=code_length)


def correlation_function(code, delay_samples, oversampling):
    """计算自相关函数"""
    n = len(code)
    code_upsampled = np.repeat(code, oversampling)
    
    # 循环移位
    shift = int(delay_samples)
    code_shifted = np.roll(code_upsampled, shift)
    
    # 计算相关值
    corr = np.correlate(code_upsampled, code_shifted, mode='same')
    return corr / len(code_upsampled)


def multipath_correlation(code, delays, amplitudes, phases, oversampling=10):
    """
    计算含多径的相关函数
    
    参数:
        code: PRN码序列
        delays: 各条路径的延迟 [码片]（直射为0）
        amplitudes: 各条路径的幅度（直射为1）
        phases: 各条路径的相位 [rad]
        oversampling: 过采样率
    """
    n = len(code)
    total_samples = n * oversampling
    corr_total = np.zeros(total_samples)
    
    for delay, amp, phase in zip(delays, amplitudes, phases):
        delay_samples = delay * oversampling
        code_upsampled = np.repeat(code, oversampling)
        code_shifted = np.roll(code_upsampled, int(delay_samples))
        
        # 对于载波相位，考虑相干叠加
        # 这里简化为幅度加权
        corr = np.correlate(code_upsampled, code_shifted, mode='same') / total_samples
        corr_total += amp * corr * np.cos(phase)  # 简化的相位影响
    
    return corr_total


def multipath_error_bpsk(delay_chips, amplitude_ratio, phase_diff):
    """
    计算BPSK信号在标准DLL下的多径码跟踪误差
    
    参数:
        delay_chips: 多径相对延迟 [码片]
        amplitude_ratio: 多径/直射幅度比
        phase_diff: 相位差 [rad]
    
    返回:
        error: 码跟踪误差 [码片]
    """
    d = abs(delay_chips)
    
    if d >= 1.0:
        # 延迟超过1码片，使用近似公式
        return 0.0  # 窄相关器可基本消除
    
    # 早迟间距为1码片的DLL（标准相关器）
    # 基于S曲线的多径误差公式
    if d < 1.0:
        # 建设性或破坏性干涉
        error = (amplitude_ratio * d * (1 - d)) / (2 + 2 * amplitude_ratio * (1 - d) * np.cos(phase_diff))
        return error if delay_chips > 0 else -error
    
    return 0.0


def simulate_ground_reflection(antenna_height, elevation_deg, freq=1575.42e6):
    """
    模拟地面反射多径
    
    参数:
        antenna_height: 天线高度 [m]
        elevation_deg: 卫星仰角 [度]
        freq: 信号频率 [Hz]
    
    返回:
        delay: 多径延迟 [码片] (C/A码)
        amplitude_ratio: 幅度比
        phase_diff: 相位差 [rad]
    """
    c = 299792458.0
    E = np.radians(elevation_deg)
    
    # 路径差（地面反射路径 - 直射路径）
    path_diff = 2 * antenna_height * np.sin(E)
    
    # 延迟差
    delay_sec = path_diff / c
    delay_chips = delay_sec * 1.023e6  # C/A码 1.023 Mcps
    
    # 反射系数（简化，假设地面反射损耗约6dB）
    # 实际应根据入射角和地面参数计算
    reflection_coeff = 0.5  # 幅度反射系数
    
    # 考虑球面波扩散损耗
    distance_direct = antenna_height / np.sin(E)  # 近似
    distance_reflect = distance_direct + path_diff
    spreading_loss = distance_direct / distance_reflect
    
    amplitude_ratio = reflection_coeff * spreading_loss
    
    # 相位差（路径差 + 反射相位翻转）
    wavelength = c / freq
    phase_diff = 2 * np.pi * path_diff / wavelength + np.pi  # 地面反射有π相位翻转
    
    return delay_chips, amplitude_ratio, phase_diff


# 多径误差分析示例
if __name__ == "__main__":
    # 生成PRN码
    code = generate_prn_code(1023)
    
    # 分析不同延迟下的多径误差
    delays = np.linspace(-2, 2, 200)  # 码片
    amplitude_ratio = 0.5  # 多径幅度为直射的一半
    
    fig, axes = plt.subplots(2, 1, figsize=(12, 8))
    
    # 同相和反相情况
    for phase, label in [(0, '同相 (0°)'), (np.pi, '反相 (180°)')]:
        errors = []
        for d in delays:
            err = multipath_error_bpsk(d, amplitude_ratio, phase)
            errors.append(err)
        axes[0].plot(delays, errors, label=label)
    
    axes[0].set_xlabel('多径延迟 [码片]')
    axes[0].set_ylabel('码跟踪误差 [码片]')
    axes[0].set_title(f'多径误差曲线 (幅度比={amplitude_ratio})')
    axes[0].legend()
    axes[0].grid(True)
    
    # 地面反射多径随仰角变化
    antenna_height = 2.0  # 天线高度2米
    elevations = np.linspace(5, 90, 100)
    delays_elev = []
    amp_ratios = []
    
    for elev in elevations:
        d, amp, _ = simulate_ground_reflection(antenna_height, elev)
        delays_elev.append(d)
        amp_ratios.append(amp)
    
    axes[1].plot(elevations, delays_elev, 'b-', label='延迟 [码片]')
    axes[1].set_xlabel('卫星仰角 [度]')
    axes[1].set_ylabel('多径延迟 [码片]', color='b')
    axes[1].tick_params(axis='y', labelcolor='b')
    
    ax2 = axes[1].twinx()
    ax2.plot(elevations, amp_ratios, 'r--', label='幅度比')
    ax2.set_ylabel('幅度比', color='r')
    ax2.tick_params(axis='y', labelcolor='r')
    
    axes[1].set_title(f'地面反射多径 (天线高度={antenna_height}m)')
    axes[1].grid(True)
    
    plt.tight_layout()
    plt.show()
    
    # 打印一些典型值
    print("地面反射多径典型值 (天线高度=2m):")
    for elev in [5, 10, 30, 60, 90]:
        d, amp, phase = simulate_ground_reflection(antenna_height, elev)
        print(f"  仰角{elev:3d}°: 延迟={d:.3f}码片, 幅度比={amp:.3f}, 相位={np.degrees(phase):.1f}°")
```

## ⚠️ 注意事项

1. **多径环境复杂性**：实际多径环境非常复杂，仿真中通常需要做适当简化。

2. **相干 vs 非相干**：多径信号可能是相干的（固定相位关系）或非相干的，取决于反射体的运动状态。

3. **天线方向图**：天线对不同方向来波的增益不同，低仰角多径可能被天线抑制。

4. **极化失配**：GNSS信号为右旋圆极化，反射后极化特性改变，导致额外的极化损耗。

5. **NLOS信号**：在城市环境中，直射信号可能被完全遮挡，此时接收到的全是反射信号（非视距）。

6. **多径与噪声的区别**：多径是系统性误差（可预测、相关），而噪声是随机误差。

7. **仿真参数选择**：
   - 多径数量：根据场景选择（开阔0-2，城市10+）
   - 延迟分布：指数分布、均匀分布或基于几何计算
   - 幅度分布：瑞利分布、莱斯分布或确定性计算
   - 相位分布：均匀分布（0-2π）

8. **动态多径**：在运动场景下，多径参数随时间变化，需要考虑多普勒效应和时变特性。
