## 🎯 概述

**导航电文（Navigation Message）** 是卫星向用户广播的二进制数据，包含了计算卫星位置、钟差、电离层模型等所需的参数。

导航电文是GNSS信号的重要组成部分：
- 调制在PRN码之上（数据码）
- 速率通常为 50 bps（GPS C/A码）
- 包含星历、历书、钟差、电离层模型、卫星健康状态等信息
- 接收机必须解调出导航电文才能进行定位

## 📡 GPS L1 C/A 导航电文

### 电文结构

GPS导航电文的基本结构：

| 层级 | 单位 | 长度 | 时间 |
| :--- | :--- | :--- | :--- |
| 最底层 | **位（bit）** | 1 bit | 20 ms |
| | **字（Word）** | 30 bits | 0.6 s |
| | **子帧（Subframe）** | 10 words = 300 bits | 6 s |
| | **帧（Frame）** | 5 subframes = 1500 bits | 30 s |
| 最高层 | **超帧（Superframe）** | 25 frames = 37500 bits | 12.5 min |

**特点**：
- 数据速率：50 bps（每bit 20ms）
- 每字30位，含6位奇偶校验（Hamming码）
- 每子帧300位，时长6秒
- 每帧5个子帧，时长30秒
- 子帧4和5各有25个页面（Page），构成超帧

### 各子帧内容

| 子帧 | 主要内容 | 是否重复 |
| :--- | :--- | :--- |
| **子帧1** | 卫星钟差参数、卫星健康状态、星期数、精度因子 | 每帧重复 |
| **子帧2** | 广播星历参数（第1部分） | 每帧重复 |
| **子帧3** | 广播星历参数（第2部分） | 每帧重复 |
| **子帧4** | 电离层参数、UTC参数、历书（部分）、特殊消息 | 25个页面轮换 |
| **子帧5** | 所有卫星的历书数据 | 25个页面轮换 |

### 子帧1：钟差参数与健康状况

**关键字段**：

| 字段 | 位数 | 比例因子 | 单位 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| TLM word | 30 | - | - | 遥测字，含同步码 |
| HOW word | 30 | - | - | 交接字，含Z计数 |
| WN | 10 | 1 | 周 | GPS周数 |
| L2 flag | 2 | - | - | L2码标志 |
| URA | 4 | - | - | 用户测距精度指数 |
| SV health | 6 | - | - | 卫星健康状态 |
| T_GD | 8 | 2⁻³¹ | s | 群延迟 |
| IODC | 10 | - | - | 时钟数据期龄 |
| t_oc | 16 | 2⁴ | s | 时钟数据参考时间 |
| a_f2 | 8 | 2⁻⁵⁵ | s/s² | 钟漂系数 |
| a_f1 | 16 | 2⁻⁴³ | s/s | 钟速系数 |
| a_f0 | 22 | 2⁻³¹ | s | 钟差系数 |

### 子帧2、3：星历参数

子帧2和3共同包含完整的广播星历参数：

| 字段 | 子帧 | 位数 | 比例因子 | 单位 |
| :--- | :--- | :--- | :--- | :--- |
| IODE | 2 | 8 | - | - |
| C_rs | 2 | 16 | 2⁻⁵ | m |
| Δn | 2 | 16 | 2⁻⁴³ | 半周/s |
| M_0 | 2 | 32 | 2⁻³¹ | 半周 |
| C_uc | 2 | 16 | 2⁻²⁹ | rad |
| e | 2,3 | 32 | 2⁻³³ | - |
| C_us | 2 | 16 | 2⁻²⁹ | rad |
| sqrt(A) | 2,3 | 32 | 2⁻¹⁹ | √m |
| t_oe | 2 | 16 | 2⁴ | s |
| C_ic | 3 | 16 | 2⁻²⁹ | rad |
| Ω_0 | 3 | 32 | 2⁻³¹ | 半周 |
| C_is | 3 | 16 | 2⁻²⁹ | rad |
| i_0 | 3 | 32 | 2⁻³¹ | 半周 |
| C_rc | 3 | 16 | 2⁻⁵ | m |
| ω | 3 | 32 | 2⁻³¹ | 半周 |
| Ω_dot | 3 | 24 | 2⁻⁴³ | 半周/s |
| IDOT | 3 | 14 | 2⁻⁴³ | 半周/s |

### 子帧4、5：历书与其他数据

子帧4和5各有25个页面，提供低精度的历书数据（Almanac）：

**历书数据特点**：
- 包含所有卫星的粗略轨道参数
- 精度低于星历（约公里级）
- 用于快速捕获（缩小搜索范围）
- 更新频率低（约每天一次）

子帧4还包含：
- 电离层模型参数（Klobuchar 8参数）
- UTC时间参数
- 特殊电文（如GPS公告）

## 🧭 北斗 B1I 导航电文

北斗导航电文分为D1和D2两种：

### D1 导航电文（区域）

- 速率：50 bps
- 适用：MEO和IGSO卫星
- 结构：每帧30秒，5个子帧
- 与GPS类似，包含星历、钟差、历书等

### D2 导航电文（全球）

- 速率：500 bps（是D1的10倍）
- 适用：GEO卫星
- 结构：每帧6秒，包含更多信息
- 更快的电文更新率

**北斗特有的参数**：
- BDT时间参数
- 北斗电离层模型（Klobuchar形式，参数不同）
- 卫星星历（与GPS类似，但单位和比例因子可能不同）

## 📊 关键参数详解

### 时间参数

**Z计数（Z-count）**：
- HOW字中的时间参数
- 表示从GPS周开始到当前子帧起始时刻的1.5秒数
- Z计数 × 6 = 周内秒数（子帧起始时刻）

**GPS周数（WN）**：
- 10位，范围0-1023
- 每1023周（约19.6年）翻转一次
- 第二次翻转预计在2038年

**t_oe / t_oc**：
- t_oe：星历参考时间
- t_oc：钟差参考时间
- 单位：秒（GPS周内秒）

### 星历参数

GPS使用**开普勒轨道参数 + 摄动项**的形式：

**开普勒6参数**：
1. $\sqrt{A}$：轨道长半轴的平方根
2. $e$：偏心率
3. $i_0$：参考时刻轨道倾角
4. $\Omega_0$：参考时刻升交点赤经
5. $\omega$：近地点角距
6. $M_0$：参考时刻平近点角

**速率参数**：
- $\Delta n$：平均运动角速度改正
- $\dot{\Omega}$（OmegaDot）：升交点赤经变化率
- $\dot{i}$（IDOT）：轨道倾角变化率

**摄动参数（各2个，正弦+余弦）**：
- $C_{uc}, C_{us}$：升交距角修正
- $C_{rc}, C_{rs}$：轨道半径修正
- $C_{ic}, C_{is}$：轨道倾角修正

### 钟差参数

卫星钟差模型：

$$
\Delta t_{sv} = a_{f0} + a_{f1}(t - t_{oc}) + a_{f2}(t - t_{oc})^2 - T_{GD}
$$

其中：
- $a_{f0}$：钟差（秒）
- $a_{f1}$：钟速（秒/秒）
- $a_{f2}$：钟漂（秒/秒²）
- $T_{GD}$：群延迟（用于L1-L2之间的修正）

### 电离层参数

GPS广播8个Klobuchar电离层模型参数：
- $\alpha_0, \alpha_1, \alpha_2, \alpha_3$：振幅系数
- $\beta_0, \beta_1, \beta_2, \beta_3$：周期系数

## 💻 代码实现示例

### Python 导航电文解析（简化版）

```python
import numpy as np
import math


def extract_bits(data, start, length):
    """
    从二进制数据中提取指定范围的位
    
    参数:
        data: 二进制数据 (整数数组或字符串)
        start: 起始位索引 (从0开始)
        length: 位数
    
    返回:
        value: 提取的整数值
    """
    # 简化实现
    value = 0
    for i in range(length):
        value = (value << 1) | data[start + i]
    return value


def twos_complement(value, bits):
    """计算补码（有符号数）"""
    if value & (1 << (bits - 1)):
        value -= 1 << bits
    return value


def parse_gps_subframe1(subframe_bits):
    """
    解析GPS子帧1
    
    参数:
        subframe_bits: 子帧数据 (300 bits)
    
    返回:
        params: 解析出的参数字典
    """
    params = {}
    
    # Word 1: TLM (遥测字)
    params['tlm_message'] = extract_bits(subframe_bits, 8, 14)
    
    # Word 2: HOW (交接字)
    z_count = extract_bits(subframe_bits, 30 + 2, 17)  # Z计数 (17位)
    params['z_count'] = z_count
    params['tow'] = z_count * 6.0  # 周内秒 (子帧起始)
    
    # Word 3: 周数 + 精度等
    wn = extract_bits(subframe_bits, 60 + 20, 10)  # WN (10位)
    params['wn'] = wn
    
    # URA (用户测距精度)
    ura_index = extract_bits(subframe_bits, 60 + 72, 4)
    params['ura_index'] = ura_index
    
    # 卫星健康状态
    sv_health = extract_bits(subframe_bits, 60 + 76, 6)
    params['sv_health'] = sv_health
    
    # IODC (时钟数据期龄)
    iodc_msb = extract_bits(subframe_bits, 60 + 82, 2)
    iodc_lsb = extract_bits(subframe_bits, 240 + 2, 8)
    iodc = (iodc_msb << 8) | iodc_lsb
    params['iodc'] = iodc
    
    # T_GD (群延迟)
    t_gd_raw = extract_bits(subframe_bits, 192 + 16, 8)
    t_gd = twos_complement(t_gd_raw, 8) * (2 ** -31)
    params['t_gd'] = t_gd
    
    # 时钟参数
    t_oc_raw = extract_bits(subframe_bits, 210 + 2, 16)
    params['t_oc'] = t_oc_raw * (2 ** 4)  # 秒
    
    a_f2_raw = extract_bits(subframe_bits, 240 + 22, 8)
    params['a_f2'] = twos_complement(a_f2_raw, 8) * (2 ** -55)  # s/s^2
    
    a_f1_raw = extract_bits(subframe_bits, 270 + 2, 16)
    params['a_f1'] = twos_complement(a_f1_raw, 16) * (2 ** -43)  # s/s
    
    a_f0_raw = extract_bits(subframe_bits, 270 + 22, 22)
    params['a_f0'] = twos_complement(a_f0_raw, 22) * (2 ** -31)  # s
    
    return params


def parse_gps_subframe2(subframe_bits):
    """解析GPS子帧2（星历第1部分）"""
    params = {}
    
    # IODE
    params['iode'] = extract_bits(subframe_bits, 60 + 60, 8)
    
    # C_rs
    crs_raw = extract_bits(subframe_bits, 60 + 68, 16)
    params['c_rs'] = twos_complement(crs_raw, 16) * (2 ** -5)  # m
    
    # Delta n
    dn_raw = extract_bits(subframe_bits, 90 + 2, 16)
    params['delta_n'] = twos_complement(dn_raw, 16) * (2 ** -43) * math.pi  # rad/s
    
    # M_0
    m0_raw = (extract_bits(subframe_bits, 90 + 24, 8) << 24) | extract_bits(subframe_bits, 120 + 2, 24)
    params['m_0'] = twos_complement(m0_raw, 32) * (2 ** -31) * math.pi  # rad
    
    # C_uc
    cuc_raw = extract_bits(subframe_bits, 150 + 2, 16)
    params['c_uc'] = twos_complement(cuc_raw, 16) * (2 ** -29)  # rad
    
    # e (偏心率)
    e_raw = (extract_bits(subframe_bits, 168 + 2, 8) << 24) | extract_bits(subframe_bits, 210 + 2, 24)
    params['e'] = e_raw * (2 ** -33)  # 无量纲
    
    # C_us
    cus_raw = extract_bits(subframe_bits, 180 + 2, 16)
    params['c_us'] = twos_complement(cus_raw, 16) * (2 ** -29)  # rad
    
    # sqrt(A)
    sqrta_raw = (extract_bits(subframe_bits, 240 + 2, 8) << 24) | extract_bits(subframe_bits, 270 + 2, 24)
    params['sqrt_a'] = sqrta_raw * (2 ** -19)  # sqrt(m)
    
    # t_oe
    toe_raw = extract_bits(subframe_bits, 270 + 26, 16)
    params['t_oe'] = toe_raw * (2 ** 4)  # s
    
    return params


def compute_satellite_clock(params, t):
    """
    根据钟差参数计算卫星钟差
    
    参数:
        params: 钟差参数字典
        t: GPS时间 (周内秒)
    
    返回:
        dt_sv: 卫星钟差 (秒)
    """
    a0 = params['a_f0']
    a1 = params['a_f1']
    a2 = params['a_f2']
    t_oc = params['t_oc']
    t_gd = params.get('t_gd', 0.0)
    
    # 时间差
    dt = t - t_oc
    # 处理周翻转

        dt -= 604800
    elif dt < -302400:
        dt += 604800
    
    # 钟差计算
    dt_sv = a0 + a1 * dt + a2 * dt * dt - t_gd
    
    return dt_sv

if __name__ == "__main__":
    print("GPS导航电文解析示例")
    print("=" * 50)
    
    # 实际应用中，子帧数据从信号跟踪中解调获得
    # 这里仅展示参数结构和计算方法
```

## ⚠️ 注意事项

1. **单位转换**：导航电文中的参数有特定的比例因子（scale factor），必须乘以正确的比例因子才能得到物理量值。

2. **有符号数**：许多参数是有符号的（补码表示），解析时需要进行符号扩展。

3. **半周 vs 弧度**：GPS电文中角度参数以**半周**（semicircles）为单位，使用时需乘以π转换为弧度。

4. **数据完整性**：每30位字有6位奇偶校验，必须验证校验通过后才能使用数据。

5. **帧同步**：解析电文前需要找到帧同步头（TLM字的前导码10001011）。

6. **IODC/IOD一致性**：星历数据期龄（IODE）和时钟数据期龄（IODC）应保持一致（通常低8位相同），否则表示数据不匹配。

7. **星历有效期**：广播星历的有效期通常为参考时刻前后2-4小时，过期后精度下降。

8. **多系统差异**：不同系统（GPS、BDS、Galileo）的导航电文格式不同，解析时需注意区分。

9. **仿真中的电文生成**：在信号仿真中，需要生成符合格式的导航电文数据，通常使用真实星历数据填入。
