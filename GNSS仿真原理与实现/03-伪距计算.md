## 🎯 概述

**伪距（Pseudorange）** 是GNSS定位中最基本的观测量。它是通过测量卫星信号从发射机到接收机的传播时间，再乘以光速得到的距离估计值。

之所以称为"伪"距，是因为这个测量值包含了**卫星钟差**、**接收机钟差**以及**大气延迟**等多种误差，并非真实的几何距离。通过联合多颗卫星的伪距观测值，可以解算出接收机的三维位置和钟差。

伪距是GNSS信号仿真中连接卫星星座仿真与信号生成的关键桥梁。

---

## 📐 伪距的基本概念

### 真实几何距离

卫星 `i` 与接收机 `u` 之间的真实几何距离为：

$$
\rho_i = \sqrt{(X_i - X_u)^2 + (Y_i - Y_u)^2 + (Z_i - Z_u)^2}
$$

其中 $(X_i, Y_i, Z_i)$ 为卫星位置，$(X_u, Y_u, Z_u)$ 为接收机位置。

### 伪距定义

伪距观测值 $P_i$ 定义为：

$$
P_i = c \cdot (t_r - t_t)
$$

其中：
- $c$ 为光速（≈ 299,792,458 m/s）
- $t_r$ 为接收机接收信号的时刻
- $t_t$ 为卫星发射信号的时刻

由于接收机时钟与卫星时钟不同步，且信号传播受大气影响，伪距并不等于真实几何距离。

---

## 🔢 伪距数学模型

完整的伪距观测方程可表示为：

$$
P_i = \rho_i + c \cdot (b_u - b_i) + I_i + T_i + \epsilon_i
$$

其中：

| 符号 | 含义 | 典型量级 |
| :--- | :--- | :--- |
| $P_i$ | 伪距观测值 | ~20,000 km |
| $\rho_i$ | 卫星到接收机的几何距离 | ~20,000 km |
| $b_u$ | 接收机钟差（秒） | 任意 |
| $b_i$ | 卫星钟差（秒） | ~ns 级 |
| $I_i$ | 电离层延迟（米） | 0 ~ 100 m（天顶方向） |
| $T_i$ | 对流层延迟（米） | ~2.3 m（天顶方向） |
| $\epsilon_i$ | 观测噪声与多径（米） | 0.1 ~ 10 m |

---

## ⚙️ 伪距计算流程

在仿真中，伪距的计算遵循以下步骤：

### 步骤1：计算信号发射时刻

由于信号传播需要时间（约60-80ms），接收机在时刻 $t_r$ 收到的信号实际上是卫星在更早的时刻 $t_t$ 发射的。

$$
t_t^{(0)} = t_r - \frac{\rho^{(0)}}{c}
$$

其中 $\rho^{(0)}$ 是初始距离估计（可用近似位置计算）。

### 步骤2：计算卫星位置（发射时刻）

根据信号发射时刻 $t_t$，使用广播星历计算卫星位置 $(X_i(t_t), Y_i(t_t), Z_i(t_t))$。

### 步骤3：迭代修正发射时刻

由于卫星在运动，需要迭代计算精确的发射时刻：

$$
\rho^{(k)} = \sqrt{(X_i(t_t^{(k-1)}) - X_u)^2 + (Y_i(t_t^{(k-1)}) - Y_u)^2 + (Z_i(t_t^{(k-1)}) - Z_u)^2}
$$

$$
t_t^{(k)} = t_r - \frac{\rho^{(k)}}{c}
$$

通常迭代2-3次即可达到纳秒级精度。

### 步骤4：应用各项误差修正

在仿真中，我们通常从"真值"几何距离出发，加入各种误差项来生成伪距观测值：

$$
P_i = \rho_i + c \cdot (b_u - b_i) + I_i + T_i + \Delta_{rel} + \Delta_{sagnac} + \epsilon_i
$$

## 📊 伪距误差源分析

### 1. 卫星钟差

卫星星载原子钟虽然精度很高（每天误差约1e-13秒量级），但仍存在偏差。

**数学模型**：

$$
b_i(t) = a_{f0} + a_{f1}(t - t_{oc}) + a_{f2}(t - t_{oc})^2
$$

其中：
- $a_{f0}$：钟差（秒）
- $a_{f1}$：钟速（秒/秒）
- $a_{f2}$：钟漂（秒/秒²）
- $t_{oc}$：时钟数据参考时间

这些参数由导航电文广播。

**修正公式**：

$$
\Delta t_{sv} = a_{f0} + a_{f1}(t - t_{oc}) + a_{f2}(t - t_{oc})^2 - t_{gd}
$$

其中 $t_{gd}$ 为群延迟参数（对于L1信号需要减去）。

### 2. 接收机钟差

接收机通常使用低成本的石英钟，钟差较大且随时间变化。在定位解算中，接收机钟差作为未知参数与位置一并求解。

在仿真中，接收机钟差可以建模为：

$$
b_u(t) = b_0 + b_1 \cdot (t - t_0) + b_2 \cdot (t - t_0)^2 + \text{随机游走}
$$

### 3. 电离层延迟

电离层（50-1000km高空）中的自由电子会使GNSS信号产生延迟，延迟量与信号频率的平方成反比。

详见 [06-电离层延迟模型.md](./06-电离层延迟模型.md)。

### 4. 对流层延迟

对流层（0-50km低空）中的大气折射会使信号传播路径弯曲，产生额外延迟。

详见 [07-对流层延迟模型.md](./07-对流层延迟模型.md)。

### 5. 相对论效应

由于卫星高速运动且处于较弱的重力场中，根据相对论，卫星钟会比地面钟走得快。

**相对论修正公式**：

$$
\Delta t_{rel} = -\frac{2 \cdot \vec{r} \cdot \vec{v}}{c^2}
$$

或者用轨道参数表示：

$$
\Delta t_{rel} = -\frac{2 \sqrt{GM \cdot A} \cdot e \cdot \sin(E)}{c^2}
$$

其中：
- $\vec{r}, \vec{v}$：卫星位置和速度矢量
- $GM$：地球引力常数
- $A$：轨道长半轴
- $e$：偏心率
- $E$：偏近点角

**典型值**：GPS卫星相对论修正约为 ±45 ns（±13.5 m）。

### 6. 地球自转修正（Sagnac效应）

由于信号传播过程中地球在自转，接收机接收到信号时的位置相对于发射时刻已经旋转了一个角度。

**修正公式**：

$$
\Delta_{sagnac} = \frac{\omega_e \cdot (X_i \cdot Y_u - Y_i \cdot X_u)}{c}
$$

其中：
- $\omega_e$：地球自转角速度（7.2921151467e-5 rad/s）
- $(X_i, Y_i)$：卫星在发射时刻的ECEF坐标
- $(X_u, Y_u)$：接收机在接收时刻的ECEF坐标

**典型值**：约几十米量级（取决于卫星方位）。

### 7. 多径效应

信号经周围物体反射后到达接收机，与直射信号叠加产生干涉，造成码相位测量偏差。

详见 [08-多径效应模型.md](./08-多径效应模型.md)。

### 8. 观测噪声

接收机热噪声、A/D量化噪声等引起的随机测量误差。

**模型**：通常建模为零均值高斯白噪声

$$
\epsilon_i \sim \mathcal{N}(0, \sigma^2)
$$

其中 $\sigma$ 与载噪比（C/N0）、信号带宽、跟踪环路带宽等有关：

$$
\sigma_{code} \approx \frac{c}{f_{code}} \cdot \sqrt{\frac{B_{n}}{2 \cdot C/N_0} \cdot \left(1 + \frac{1}{T \cdot C/N_0}\right)}
$$

对于GPS C/A码，典型的伪距测量噪声约为 0.3 ~ 3 米。

## 🧪 代码实现示例

### Python 实现

```python
import math
import numpy as np

# 物理常数
C = 299792458.0       # 光速 (m/s)
OMEGA_E = 7.2921151467e-5  # 地球自转角速度 (rad/s)
GM = 3.9860050e14     # 地球引力常数 (m³/s²)


def compute_pseudorange(sat_pos, rx_pos, rx_clock_error, 
                       sat_clock_error, iono_delay, trop_delay, 
                       noise_std=0.5):
    """
    计算单颗卫星的伪距观测值（仿真用）
    
    参数:
        sat_pos: 卫星位置 (X, Y, Z) [m]
        rx_pos: 接收机位置 (X, Y, Z) [m]
        rx_clock_error: 接收机钟差 [s]
        sat_clock_error: 卫星钟差 [s]
        iono_delay: 电离层延迟 [m]
        trop_delay: 对流层延迟 [m]
        noise_std: 观测噪声标准差 [m]
    
    返回:
        pseudorange: 伪距观测值 [m]
    """
    # 1. 计算几何距离
    dx = sat_pos[0] - rx_pos[0]
    dy = sat_pos[1] - rx_pos[1]
    dz = sat_pos[2] - rx_pos[2]
    rho = math.sqrt(dx*dx + dy*dy + dz*dz)
    
    # 2. 计算地球自转修正 (Sagnac效应)
    sagnac = OMEGA_E * (sat_pos[0] * rx_pos[1] - sat_pos[1] * rx_pos[0]) / C
    
    # 3. 计算相对论修正（简化，通常已包含在卫星钟差中）
    # 完整计算需要卫星速度
    
    # 4. 组合所有项
    pseudorange = (rho 
                   + C * (rx_clock_error - sat_clock_error)
                   + iono_delay 
                   + trop_delay
                   + sagnac
                   + np.random.normal(0, noise_std))
    
    return pseudorange


def compute_satellite_clock_error(clock_params, t):
    """
    计算卫星钟差
    
    参数:
        clock_params: 字典，包含 a0, a1, a2, toc, tgd
        t: 当前GPS时间 [s 周内秒]
    
    返回:
        clock_error: 卫星钟差 [s]
    """
    a0 = clock_params['a0']    # 钟差系数
    a1 = clock_params['a1']    # 钟速系数
    a2 = clock_params['a2']    # 钟漂系数
    toc = clock_params['toc']  # 时钟参考时间
    tgd = clock_params['tgd']  # 群延迟
    
    # 计算时间差（考虑周翻转）
    dt = t - toc
    if dt > 302400:
        dt -= 604800
    elif dt < -302400:
        dt += 604800
    
    # 多项式模型
    clock_error = a0 + a1 * dt + a2 * dt * dt - tgd
    
    return clock_error


def compute_relativistic_correction(ephemeris, E_k):
    """
    计算相对论效应修正
    
    参数:
        ephemeris: 星历参数字典
        E_k: 偏近点角 [rad]
    
    返回:
        rel_correction: 相对论修正 [s]
    """
    A = ephemeris['sqrtA'] ** 2
    e = ephemeris['e']
    
    rel_correction = -2.0 * math.sqrt(GM * A) * e * math.sin(E_k) / (C ** 2)
    
    return rel_correction


# 使用示例
if __name__ == "__main__":
    # 模拟卫星和接收机位置
    sat_pos = [20000000, 10000000, 5000000]  # 卫星位置 (m)
    rx_pos = [1000000, 5000000, 3000000]     # 接收机位置 (m)
    
    # 计算伪距
    pr = compute_pseudorange(
        sat_pos=sat_pos,
        rx_pos=rx_pos,
        rx_clock_error=1e-6,    # 接收机钟差 1微秒
        sat_clock_error=1e-9,   # 卫星钟差 1纳秒
        iono_delay=5.0,         # 电离层延迟 5米
        trop_delay=2.3,         # 对流层延迟 2.3米
        noise_std=0.5           # 噪声 0.5米
    )
    
    print(f"伪距观测值: {pr:.3f} m")
```

## ⚠️ 注意事项

1. **单位一致性**：确保所有时间单位为秒，距离单位为米。

2. **时间系统**：伪距计算中使用的时间必须是统一的GNSS系统时（如GPST），需要注意卫星钟差的修正。

3. **迭代计算**：对于高精度仿真，应迭代计算信号发射时刻，通常2-3次迭代即可。

4. **天顶方向**：电离层和对流层延迟通常以天顶方向为基准，实际倾斜路径上的延迟需要乘以投影函数。

5. **误差叠加**：在仿真中，各项误差是叠加还是独立生成需要明确，避免重复计算。

6. **频率相关**：电离层延迟与频率平方成反比，多频接收机可以利用这一特性进行电离层修正。

7. **钟差定义**：注意卫星钟差的符号定义（有的定义为 t_sv = t - b，有的为 t_sv = t + b）。
