## 🎯 概述

**多普勒效应（Doppler Effect）** 是指由于波源与观测者之间存在相对运动，导致观测到的波的频率与波源发出的频率不同的现象。

在GNSS中：
- 卫星高速运动（约3.8 km/s），产生显著的多普勒频移
- 接收机运动也会产生多普勒频移
- 多普勒频移是信号捕获和跟踪中的重要参数
- 多普勒观测值可用于速度估计和辅助定位

---

## 📐 多普勒效应基本原理

### 经典多普勒公式

当波源和观测者在同一直线上运动时：

$$
f_r = f_t \cdot \frac{c + v_r}{c - v_s}
$$

其中：
- $f_t$：发射频率
- $f_r$：接收频率
- $c$：波速（光速）
- $v_r$：观测者朝向波源的速度（靠近为正）
- $v_s$：波源朝向观测者的速度（靠近为正）

由于 GNSS 中 $v \ll c$（卫星速度约 3.8 km/s，光速约 300,000 km/s），可以近似为：

$$
f_r \approx f_t \cdot \left(1 + \frac{v_r + v_s}{c}\right)
$$

### GNSS中的多普勒效应

对于GNSS，多普勒频移由卫星和接收机的**相对径向速度**决定：

$$
f_d = f_t \cdot \frac{(\vec{v}_u - \vec{v}_s) \cdot \vec{L}}{c}
$$

其中：
- $\vec{v}_s$：卫星速度矢量
- $\vec{v}_u$：接收机速度矢量
- $\vec{L}$：卫星到接收机的单位视线矢量（从卫星指向接收机）

注意符号约定：
- 当卫星靠近接收机时，多普勒频移为**正**（频率升高）
- 当卫星远离接收机时，多普勒频移为**负**（频率降低）

## 🧮 多普勒频移计算

### 基于位置和速度的计算

已知卫星位置 $\vec{r}_s$、卫星速度 $\vec{v}_s$、接收机位置 $\vec{r}_u$、接收机速度 $\vec{v}_u$：

**步骤1：计算视线矢量**

$$
\vec{\rho} = \vec{r}_u - \vec{r}_s
$$

$$
\rho = |\vec{\rho}| = \sqrt{(X_u - X_s)^2 + (Y_u - Y_s)^2 + (Z_u - Z_s)^2}
$$

单位视线矢量（从卫星指向接收机）：

$$
\vec{L} = \frac{\vec{\rho}}{\rho}
$$

**步骤2：计算相对径向速度**

卫星相对于接收机的径向速度（沿视线方向）：

$$
v_{rad} = \vec{v}_s \cdot \vec{L} - \vec{v}_u \cdot \vec{L} = (\vec{v}_s - \vec{v}_u) \cdot \vec{L}
$$

（$v_{rad} > 0$ 表示卫星远离接收机，多普勒为负）

**步骤3：计算多普勒频移**

$$
f_d = -\frac{f_t}{c} \cdot v_{rad} = \frac{f_t}{c} \cdot (\vec{v}_u - \vec{v}_s) \cdot \vec{L}
$$

或者用位置和速度分量直接计算：

$$
f_d = \frac{f_t}{c \cdot \rho} \cdot \left[ (X_u - X_s)(\dot{X}_u - \dot{X}_s) + (Y_u - Y_s)(\dot{Y}_u - \dot{Y}_s) + (Z_u - Z_s)(\dot{Z}_u - \dot{Z}_s) \right]
$$

### 基于星历的计算

在仿真中，通常通过广播星历同时计算卫星位置和速度：

**卫星速度的计算**（对位置公式求导）：

1. 偏近点角变化率：
   $$
   \dot{E} = \frac{n}{1 - e \cos(E)}
   $$

2. 真近点角变化率：
   $$
   \dot{\nu} = \frac{\sqrt{1 - e^2} \cdot n}{1 - e \cos(E)}
   $$

3. 轨道平面内速度，然后旋转到ECEF坐标系。

完整的卫星速度计算需要考虑摄动项的影响。

## 📊 多普勒频移的特性

### 典型量级

以 GPS L1（1575.42 MHz）为例：

| 场景 | 速度 | 多普勒频移 |
| :--- | :--- | :--- |
| **卫星运动（最大径向）** | ~900 m/s | ~±4.7 kHz |
| **地面静态接收机** | 0 m/s | ~±4.7 kHz（由卫星运动引起） |
| **车载接收机** | ~30 m/s | ~±160 Hz（由接收机运动引起） |
| **机载接收机** | ~250 m/s | ~±1.3 kHz |
| **高动态（导弹）** | ~2000 m/s | ~±10 kHz |

**捕获搜索范围**：
- 地面静态：±5 kHz（只考虑卫星运动）
- 车载：±6 kHz
- 机载：±10 kHz
- 高动态：±20 kHz 或更大

### 随时间的变化

对于一颗过境卫星（仰角从0到90再到0）：
- 卫星从地平线升起时：多普勒频移最大正（靠近）
- 卫星过天顶时：多普勒频移为0（径向速度为0）
- 卫星落下时：多普勒频移最大负（远离）

多普勒变化率（多普勒的一阶导数）也是一个重要参数：
- 影响PLL/FLL的跟踪性能
- 高动态接收机需要考虑二阶频率变化率

## 📡 多普勒观测值

### 多普勒与伪距率

多普勒频移与伪距变化率（距离率）有直接关系：

$$
\dot{\rho} = -\frac{c}{f_t} \cdot f_d
$$

即伪距率等于光速乘以多普勒频移除以载波频率，符号相反。

**应用**：
- 速度估计
- 位置辅助（卡尔曼滤波中作为观测值）
- 载波辅助码跟踪

### 多普勒积分与载波相位

多普勒频移对时间积分就是载波相位的变化量：

$$
\phi(t_2) - \phi(t_1) = -\int_{t_1}^{t_2} f_d(\tau) d\tau
$$

这也是为什么载波相位测量精度远高于伪距的原因——频率（多普勒）可以被非常精确地测量。

## 💻 代码实现示例

### Python 多普勒频移计算

```python
import numpy as np
import math

C = 299792458.0  # 光速 (m/s)
OMEGA_E = 7.2921151467e-5  # 地球自转角速度 (rad/s)


def compute_doppler(sat_pos, sat_vel, rx_pos, rx_vel, frequency):
    """
    计算多普勒频移
    
    参数:
        sat_pos: 卫星位置 (X, Y, Z) [m]
        sat_vel: 卫星速度 (Vx, Vy, Vz) [m/s]
        rx_pos: 接收机位置 (X, Y, Z) [m]
        rx_vel: 接收机速度 (Vx, Vy, Vz) [m/s]
        frequency: 载波频率 [Hz]
    
    返回:
        doppler: 多普勒频移 [Hz]
        range_rate: 伪距率 [m/s]（距离变化率）
    """
    # 视线矢量（卫星到接收机）
    dx = rx_pos[0] - sat_pos[0]
    dy = rx_pos[1] - sat_pos[1]
    dz = rx_pos[2] - sat_pos[2]
    rho = math.sqrt(dx*dx + dy*dy + dz*dz)
    
    # 单位视线矢量
    Lx = dx / rho
    Ly = dy / rho
    Lz = dz / rho
    
    # 相对速度沿视线方向的分量
    # 卫星速度在视线方向的投影
    v_sat_radial = sat_vel[0] * Lx + sat_vel[1] * Ly + sat_vel[2] * Lz
    # 接收机速度在视线方向的投影
    v_rx_radial = rx_vel[0] * Lx + rx_vel[1] * Ly + rx_vel[2] * Lz
    
    # 相对径向速度（卫星相对于接收机，沿视线方向）
    range_rate = v_sat_radial - v_rx_radial  # 正值表示距离增加
    
    # 多普勒频移
    doppler = -frequency / C * range_rate
    
    return doppler, range_rate


def compute_satellite_velocity(ephemeris, t):
    """
    基于广播星历计算卫星速度（简化版）
    
    参数:
        ephemeris: 星历参数字典
        t: GPS周内秒 [s]
    
    返回:
        velocity: 卫星速度 (Vx, Vy, Vz) [m/s]
    """
    # 提取参数
    sqrtA = ephemeris['sqrtA']
    e = ephemeris['e']
    M0 = ephemeris['M0']
    omega = ephemeris['omega']
    i0 = ephemeris['i0']
    Omega0 = ephemeris['Omega0']
    Delta_n = ephemeris['Delta_n']
    IDOT = ephemeris['IDOT']
    OmegaDot = ephemeris['OmegaDot']
    toe = ephemeris['toe']
    Cuc = ephemeris['Cuc']
    Cus = ephemeris['Cus']
    Crc = ephemeris['Crc']
    Crs = ephemeris['Crs']
    Cic = ephemeris['Cic']
    Cis = ephemeris['Cis']
    
    GM = 3.9860050e14
    OmegaDot_e = 7.2921151467e-5
    
    # 时间偏移
    tk = t - toe
    if tk > 302400:
        tk -= 604800
    elif tk < -302400:
        tk += 604800
    
    # 平均角速度
    A = sqrtA ** 2
    n0 = math.sqrt(GM / A**3)
    n = n0 + Delta_n
    
    # 平近点角
    Mk = M0 + n * tk
    
    # 求解偏近点角 (牛顿迭代)
    Ek = Mk
    for _ in range(10):
        dE = (Mk - (Ek - e * math.sin(Ek))) / (1 - e * math.cos(Ek))
        Ek += dE
        if abs(dE) < 1e-12:
            break
    
    # 真近点角
    sin_nu = math.sqrt(1 - e**2) * math.sin(Ek) / (1 - e * math.cos(Ek))
    cos_nu = (math.cos(Ek) - e) / (1 - e * math.cos(Ek))
    nuk = math.atan2(sin_nu, cos_nu)
    
    # 升交距角
    Phi_k = nuk + omega
    
    # 摄动修正
    du_k = Cus * math.sin(2*Phi_k) + Cuc * math.cos(2*Phi_k)
    dr_k = Crs * math.sin(2*Phi_k) + Crc * math.cos(2*Phi_k)
    di_k = Cis * math.sin(2*Phi_k) + Cic * math.cos(2*Phi_k)
    
    u_k = Phi_k + du_k
    r_k = A * (1 - e * math.cos(Ek)) + dr_k
    i_k = i0 + IDOT * tk + di_k
    
    # 升交点赤经
    Omega_k = Omega0 + (OmegaDot - OmegaDot_e) * tk - OmegaDot_e * toe
    
    # 轨道平面内位置
    x_k = r_k * math.cos(u_k)
    y_k = r_k * math.sin(u_k)
    
    # ECEF位置
    X = x_k * math.cos(Omega_k) - y_k * math.cos(i_k) * math.sin(Omega_k)
    Y = x_k * math.sin(Omega_k) + y_k * math.cos(i_k) * math.cos(Omega_k)
    Z = y_k * math.sin(i_k)
    
    # --- 速度计算 ---
    
    # 偏近点角变化率
    Edot_k = n / (1 - e * math.cos(Ek))
    
    # 真近点角变化率
    nudot_k = math.sqrt(1 - e**2) * n / (1 - e * math.cos(Ek))
    
    # 摄动项变化率（简化，忽略摄动对速度的二阶影响）
    # 完整计算需要考虑du_k/dt, dr_k/dt等
    
    # 轨道平面内速度
    vx_k = -r_k * nudot_k * math.sin(u_k)  # 简化
    vy_k = r_k * nudot_k * math.cos(u_k)   # 简化
    
    # 升交点赤经变化率
    Omega_dot_k = OmegaDot - OmegaDot_e
    
    # 轨道倾角变化率
    i_dot_k = IDOT
    
    # ECEF速度（简化，未包含所有摄动项）
    Vx = (vx_k * math.cos(Omega_k) 
          - vy_k * math.cos(i_k) * math.sin(Omega_k)
          + y_k * math.sin(i_k) * i_dot_k * math.sin(Omega_k)
          - Y * Omega_dot_k)
    
    Vy = (vx_k * math.sin(Omega_k) 
          + vy_k * math.cos(i_k) * math.cos(Omega_k)
          - y_k * math.sin(i_k) * i_dot_k * math.cos(Omega_k)
          + X * Omega_dot_k)
    
    Vz = vy_k * math.sin(i_k) + y_k * math.cos(i_k) * i_dot_k
    
    return np.array([X, Y, Z]), np.array([Vx, Vy, Vz])


# 使用示例
if __name__ == "__main__":
    # GPS L1 频率
    f_l1 = 1575.42e6  # Hz
    
    # 示例卫星位置和速度（模拟）
    sat_pos = np.array([20000000.0, 5000000.0, 10000000.0])  # m
    sat_vel = np.array([500.0, 2000.0, -1500.0])  # m/s
    
    # 接收机位置和速度（地面静态）
    rx_pos = np.array([1000000.0, 5000000.0, 3000000.0])  # m
    rx_vel = np.array([0.0, 0.0, 0.0])  # m/s (静态)
    
    # 计算多普勒
    doppler, range_rate = compute_doppler(sat_pos, sat_vel, rx_pos, rx_vel, f_l1)
    
    print(f"卫星位置: {sat_pos} m")
    print(f"卫星速度: {sat_vel} m/s")
    print(f"接收机位置: {rx_pos} m")
    print(f"接收机速度: {rx_vel} m/s")
    print()
    print(f"多普勒频移 (L1): {doppler:.2f} Hz")
    print(f"伪距率: {range_rate:.2f} m/s")
    print()
    
    # 计算不同接收机速度下的多普勒
    print("不同运动状态下的多普勒频移:")
    scenarios = [
        ("静态", 0, 0, 0),
        ("向东 30m/s", 30, 0, 0),
        ("向北 30m/s", 0, 30, 0),
        ("向上 10m/s", 0, 0, 10),
        ("高速 500m/s", 300, 400, 0),
    ]
    
    for name, vx, vy, vz in scenarios:
        rx_vel_test = np.array([vx, vy, vz])
        dop, rr = compute_doppler(sat_pos, sat_vel, rx_pos, rx_vel_test, f_l1)
        print(f"  {name:12s}: {dop:8.2f} Hz, 伪距率: {rr:8.2f} m/s")
```

## ⚠️ 注意事项

1. **符号约定**：不同文献中多普勒的符号定义可能不同（有的定义为接收频率减发射频率，有的相反），使用时需注意。

2. **相对论修正**：高精度应用中，多普勒频移需要考虑相对论效应（卫星钟的引力红移和时间膨胀）。

3. **电离层影响**：电离层会影响信号的群速度和相速度，从而对多普勒测量产生微小影响。

4. **地球自转**：计算多普勒时，卫星位置和速度通常在ECEF坐标系下，已经隐含了地球自转的影响。

5. **采样率**：多普勒观测值的精度与积分时间有关，积分时间越长，频率分辨率越高，但响应越慢。

6. **多径影响**：多径效应会导致多普勒测量出现偏差，特别是在多径严重的环境中。

7. **仿真中的多普勒**：在信号仿真中，多普勒频移表现为载波频率的偏移，需要在生成信号时加入。
