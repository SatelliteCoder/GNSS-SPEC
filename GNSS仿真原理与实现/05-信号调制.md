## 🎯 概述

全球导航卫星系统（GNSS）信号是经过精密设计的**伪随机码扩频信号**。其调制方式的选择直接决定了信号的**抗干扰能力**、**多径分辨力**、**码跟踪精度**以及与其它系统的**频谱兼容性**。

**为什么用扩频？**

| 优势 | 说明 |
| :--- | :--- |
| **抗干扰** | 扩频增益将干扰信号功率扩散，提高信噪比 |
| **多址能力** | 不同卫星使用不同PRN码，可在同一频率上同时传输 |
| **保密性** | 伪随机码类似噪声，不易被截获 |
| **测距精度** | 码片速率决定了测距分辨率 |
| **抗多径** | 宽带信号具有更好的多径分辨能力 |

本指南深入解析主流GNSS信号的调制方案、数学表达及其仿真实现方法。

## 🧬 伪随机码（PRN）生成原理

### m序列（最大长度序列）

m序列是由线性反馈移位寄存器（LFSR）产生的最长周期序列。

**特点**：
- 长度：$N = 2^n - 1$（n为寄存器级数）
- 平衡性：1比0多一个
- 游程特性：长度为k的游程占总游程的$1/2^k$
- 自相关函数：理想的二值自相关（1 和 -1/N）

**生成方式**：
通过n级移位寄存器和特定的反馈多项式生成。例如GPS G1码的生成多项式为：
$$
G_1(x) = x^{10} + x^3 + 1
$$

### Gold码

Gold码是由一对m序列（优选对）通过模二加生成的码族：

$$
G_{i}(t) = G_1(t) \oplus G_2(t + iT_c)
$$

其中 $i$ 是G2码相对于G1码的相位偏移（码片）。

**特点**：
- 码数量多：n级移位寄存器可生成 $2^n + 1$ 个不同的Gold码
- 互相关特性好：最大互相关值约为 $2^{-(n-1)/2}$
- 自相关特性：不如m序列理想，但足够好

**GPS C/A码**就是Gold码的典型应用。

### 自相关与互相关特性

**自相关函数**：

$$
R(\tau) = \frac{1}{T} \int_0^T C(t) C(t - \tau) dt
$$

对于理想的PRN码（周期码）：
- 当 $\tau = 0$ 时，$R(0) = 1$（峰值）
- 当 $\tau \neq kT_c$ 时，$R(\tau) \approx -1/N$（底噪）

自相关函数形状为三角形（码片宽度内线性变化）。

**互相关函数**：

$$
R_{ij}(\tau) = \frac{1}{T} \int_0^T C_i(t) C_j(t - \tau) dt
$$

对于Gold码，最大互相关值约为：
$$
|R_{max}| \approx \frac{2^{(n+1)/2} + 1}{N}
$$

对于GPS C/A码（n=10, N=1023）：
- 最大互相关约为 -24 dB（约6.3%）
- 这意味着强信号可能通过互相关干扰弱信号的捕获（远近效应）

### GPS C/A码生成

GPS C/A码由两个10级移位寄存器G1和G2生成：

- **G1多项式**：$x^{10} + x^3 + 1$
- **G2多项式**：$x^{10} + x^9 + x^8 + x^6 + x^3 + x^2 + 1$
- **码长**：1023 码片
- **码速率**：1.023 Mcps
- **周期**：1 ms

每颗卫星使用不同的G2初始相位（或抽头组合）来生成不同的PRN码。GPS定义了37种PRN码（32颗卫星 + 5个备用）。

### 北斗B1I码生成

北斗B1I的测距码由两个11级移位寄存器G1和G2生成：

- **码长**：2046 码片（是GPS的2倍）
- **码速率**：2.046 Mcps（是GPS的2倍）
- **周期**：1 ms

更长的码长和更高的码速率提供了更好的抗干扰性能和测距精度。

## 1. GNSS 信号组成

一个基本的GNSS信号基带数学模型可以表示为：

$$
s(t) = A \cdot D(t) \cdot C(t) \cdot S(t)
$$

其中：
- $A$：信号振幅
- $D(t)$：导航电文数据码（取值为 ±1）
- $C(t)$：伪随机噪声码（PRN Code，取值为 ±1）
- $S(t)$：子载波（Subcarrier，对于BPSK，$S(t) = 1$；对于BOC，$S(t)$为方波）

该基带信号最终被调制到射频载波 $f_c$ 上：

$$
s_{RF}(t) = s_I(t) \cdot \cos(2\pi f_c t) - s_Q(t) \cdot \sin(2\pi f_c t)
$$

其中 $s_I(t)$ 和 $s_Q(t)$ 分别是同相和正交支路的基带信号。

**信号层级结构**：
```
载波 f_c (GHz级)
  ↓ 调制
子载波 S(t) (MHz级，BOC才有)
  ↓ 模二加
PRN码 C(t) (Mcps级)
  ↓ 模二加
数据码 D(t) (bps级, 如50bps)
```

## 2. 核心调制技术

### 2.1 二进制相移键控 (BPSK)

**BPSK(𝑛)** 是最简单的调制方式，其中 `n` 表示码片速率（单位：Mcps）。其子载波 $S(t)=1$。

- **实现公式**：
  $$
  s_{BPSK}(t) = A \cdot D(t) \cdot C(t)
  $$
- **功率谱密度（PSD）主瓣宽度**：$2 \times n$ MHz
- **自相关函数**：三角形，底边宽2码片
- **码跟踪误差**：与码片宽度成正比

**特点**：
- 实现简单，抗噪性能好
- 频谱效率相对较低
- 是最早的GNSS信号调制方式

**应用**：GPS L1 C/A, GPS L2C, BDS B1I, GLONASS L1 等。

### 2.2 二进制偏移载波 (BOC)

**BOC(𝑚, 𝑛)** 通过一个频率为 $f_s = m \times 1.023$ MHz 的方波子载波对PRN码进行二次调制。

- `m`：子载波频率系数（$f_s = m \times 1.023$ MHz）
- `n`：码速率系数（$f_{code} = n \times 1.023$ Mcps）

**实现公式**：
$$
s_{BOC}(t) = A \cdot D(t) \cdot C(t) \cdot \text{sign}(\sin(2\pi f_s t))
$$

**方波子载波**：
$$
S(t) = \text{sign}(\sin(2\pi f_s t)) = \begin{cases}
+1, & \sin(2\pi f_s t) \geq 0 \\
-1, & \sin(2\pi f_s t) < 0
\end{cases}
$$

**功率谱密度（PSD）**：
- 频谱分裂为两个边带，中心频率处有零点
- 主瓣位于 $\pm f_s$ 处
- 主瓣宽度：$2 \times n$ MHz（每边）

**BOC的分类**：

| 类型 | 相位 | 说明 |
| :--- | :--- | :--- |
| **sin-BOC** | 正弦相位 | 最常见，如GPS M码 BOC(10,5) |
| **cos-BOC** | 余弦相位 | 边带对称，如Galileo E1 OS |

**特点**：
- **优点**：
  - 更高的码跟踪精度（Gabor带宽更大）
  - 更好的多径抑制能力（更窄的相关峰主峰）
  - 频谱兼容性好（可与BPSK信号共享频段）
- **缺点**：
  - 相关函数有多个峰（主峰 + 边峰），存在模糊问题
  - 需要复杂的跟踪技术（如Bump-Jump、Double Estimator）
  - 捕获更复杂

**BOC相关峰特性**：
- 主峰位于 $\tau = 0$
- 边峰位于 $\tau = \pm T_s, \pm 2T_s, \ldots$
- BOC(1,1)的边峰幅度约为主峰的70%
- 阶数越高（m/n越大），主峰越窄越尖，但边峰越多

### 2.3 正交复用 (QPSK, AltBOC)

用于在一个载波上高效复用两个或多个信号分量。

**QPSK**：传统的正交相移键控，I、Q两支路分别调制不同的信号。

$$
s_{QPSK}(t) = s_I(t)\cdot\cos(2\pi f_c t) - s_Q(t)\cdot\sin(2\pi f_c t)
$$

**优点**：频谱利用率翻倍
**缺点**：包络不恒定（变化范围 0 ~ 最大值）

**AltBOC（交替二进制偏移载波）**：

一种高级的恒包络调制技术，可将4个信号分量（两个数据 + 两个导频）复用到单个载波上，同时保持BOC-like的优越性能。

**特点**：
- 恒包络（恒定幅度）
- 4个信号分量复用到一个载波频率
- 上下边带各有一个数据通道和一个导频通道
- 类似两个BOC信号的组合，但实现更复杂
- **应用**：Galileo E5 信号 (AltBOC(15,10))

### 2.4 MBOC / CBOC / TMBOC

**MBOC（Multiplexed BOC）**：
BOC(1,1) 和 BOC(6,1) 的功率加权复合：

$$
\text{MBOC}(6,1,1/11) = \frac{10}{11} \text{BOC}(1,1) + \frac{1}{11} \text{BOC}(6,1)
$$

即在BOC(1,1)的基础上，增加了1/11功率的BOC(6,1)高频分量。

**目的**：提高码跟踪精度和多径抑制能力，同时保持与BOC(1,1)的后向兼容。

**变体**：

| 类型 | 实现方式 | 应用 |
| :--- | :--- | :--- |
| **CBOC** | Composite BOC，BOC(1,1)和BOC(6,1)同相叠加 | Galileo E1 OS |
| **TMBOC** | Time-multiplexed BOC，时分复用 | GPS L1C |
| **QMBOC** | Quadrature multiplexed BOC，正交复用 | BDS B1C |

## 📊 功率谱密度 (PSD)

### BPSK的PSD

对于BPSK(n)信号，归一化功率谱密度为：

$$
S_{BPSK}(f) = T_c \cdot \text{sinc}^2(\pi f T_c)
$$

其中 $T_c = 1 / f_{code}$ 为码片宽度。

**特点**：
- 主瓣中心在 f=0 处
- 主瓣宽度：$2 f_{code}$
- 第一个零点在 $\pm f_{code}$ 处
- 旁瓣按 $1/f^2$ 衰减

### BOC的PSD

对于BOC(m,n)信号：

$$
S_{BOC}(f) = T_c \cdot \text{sinc}^2\left(\frac{\pi f T_c}{2}\right) \cdot \tan^2\left(\frac{\pi f}{2 f_s}\right)
$$

（简化公式，实际更复杂）

**特点**：
- 频谱分裂为两个主峰
- 中心频率处功率为0（零点）
- 主峰位于 $\pm f_s$ 处
- 每个主峰宽度约为 $2 f_{code}$

**BOC频谱偏移的意义**：
- 可以与同频的BPSK信号共存（频谱交叠小）
- 例如：GPS L1 C/A (BPSK(1)) 和 Galileo E1 OS (CBOC) 都在 1575.42 MHz

## 🔒 恒包络多路复用技术

### 为什么需要恒包络？

卫星上的功率放大器（TWTA，行波管放大器）通常工作在**饱和状态**以获得最高效率：
- 饱和状态效率最高（≈50-60%）
- 但饱和放大器会引入非线性失真
- 如果输入信号包络有变化，会产生互调失真，导致频谱扩散
- 因此，星上发射的信号必须是**恒包络**的

**恒包络的重要性**：
- 最大限度利用星上有限的功率
- 避免非线性失真导致的频谱扩散
- 保证信号质量符合频谱掩膜要求

### Interplex / CASM

**Interplex（Interleaved）** / **CASM（Coherent Adaptive Subcarrier Modulation）**：

将多个信号分量复用到同一载波上并保持恒包络的技术。

**基本思想**：
- 使用互调项来补偿幅度变化
- 虽然引入了互调分量，但整体保持恒包络
- 互调分量的功率尽量小

**典型应用**：
- GPS L1：C/A码 + P码 复用
- GPS L2：P码 + L2C 复用

### AltBOC多路复用

AltBOC是一种更先进的恒包络复用技术：

- 可将4个信号分量（2个数据 + 2个导频）复用到单个载波
- 上下边带独立，类似两个BOC信号
- 恒包络，功率效率高
- 但接收机实现更复杂

**应用**：Galileo E5a + E5b 复用到E5频段

## 3. 各系统信号调制详解

| :--- | :--- | :--- | :--- | :--- | :--- |

| | P(Y) | BPSK(10) | 10.23 Mcps | 50 bps | 军用加密，抗干扰强 |

- E5是目前最宽的GNSS信号频段（511.15 MHz带宽），测距精度最高
- E6是商业服务频段，加密授权使用

**说明**：
- BDS-3实现了与GPS和Galileo的多频互操作（B1C、B2a）
- B2b提供PPP精密单点定位服务（星基增强）
- B1I向后兼容BDS-2，保证了系统平稳过渡

### 3.4 GLONASS (俄罗斯)

| 频点 | 信号 | 调制方式 | 特点 |
| :--- | :--- | :--- | :--- |
| **L1 (1602+k×0.5625 MHz)** | SP | BPSK(0.511) | FDMA，码速0.511Mcps |
| **L2 (1246+k×0.4375 MHz)** | SP | BPSK(0.511) | FDMA |
| **L3 (1202.025 MHz)** | CDMA | BOC(1,1) | 现代化信号，向CDMA过渡 |
| **L1OC, L2OC** | CDMA | BPSK(5.115) | 新的开放CDMA信号 |

**特点**：
- GLONASS采用**FDMA（频分多址）**，每颗卫星使用不同的频率（k为频道号，k=-7...+6）
- 与GPS/BDS/Galileo的CDMA（码分多址）体制不同
- 现代化信号L3、L1OC、L2OC已采用CDMA体制，与国际接轨
- FDMA的优点：互相关干扰小；缺点：接收机射频前端更复杂

## 4. 实现与仿真

以下是使用 Python 进行 BPSK 和 BOC 调制基带信号生成的完整代码示例。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import signal


def generate_m_sequence(feedback_poly, n):
    """
    生成m序列（最大长度序列）
    
    参数:
        feedback_poly: 反馈多项式（从最高位到最低位），例如 [10, 3] 表示 x^10 + x^3 + 1
        n: 寄存器级数
    
    返回:
        seq: m序列 (长度 2^n - 1，值为 ±1)
    """
    N = 2**n - 1
    reg = np.ones(n, dtype=int)  # 初始全1
    seq = np.zeros(N, dtype=int)
    
    for i in range(N):
        seq[i] = reg[0]
        # 计算反馈
        feedback = 0
        for tap in feedback_poly:
            feedback ^= reg[tap - 1]  # tap是从1开始的位置
        # 移位
        reg[:-1] = reg[1:]
        reg[-1] = feedback
    
    # 转换为 ±1
    return 1 - 2 * seq


def generate_gold_code(g1_poly, g2_poly, n, g2_phase):
    """
    生成Gold码（简化版）
    
    参数:
        g1_poly: G1反馈多项式
        g2_poly: G2反馈多项式
        n: 寄存器级数
        g2_phase: G2初始相位偏移（码片数）
    """
    g1 = generate_m_sequence(g1_poly, n)
    g2 = generate_m_sequence(g2_poly, n)
    
    # 将G2移位
    g2_shifted = np.roll(g2, g2_phase)
    
    # 模二加
    gold_code = g1 * g2_shifted  # 因为值为±1，相乘等价于模二加
    
    return gold_code


def generate_bpsk_signal(data_bits, prn_code, samples_per_chip):
    """
    生成BPSK调制基带信号
    """
    # 数据码与PRN码相乘（扩频）
    # 每个数据位包含一整个PRN码周期
    spread = np.outer(data_bits, prn_code).flatten()
    
    # 上采样（每个码片 samples_per_chip 个采样点）
    s_bpsk = np.repeat(spread, samples_per_chip)
    
    return s_bpsk


def generate_boc_signal(data_bits, prn_code, samples_per_chip, m, n_order, 
                       boc_type='sin'):
    """
    生成BOC调制信号
    
    参数:
        m, n_order: BOC(m, n) 参数（子载波频率系数，码速率系数）
        boc_type: 'sin' 或 'cos'
    """
    f_s = m * 1.023e6           # 子载波频率
    f_code = n_order * 1.023e6   # 码速率
    
    # 1. 生成扩频序列（同BPSK）
    spread = np.outer(data_bits, prn_code).flatten()
    spread_upsampled = np.repeat(spread, samples_per_chip)
    
    # 2. 生成BOC子载波（方波）
    total_samples = len(spread_upsampled)
    sample_rate = f_code * samples_per_chip
    t = np.arange(total_samples) / sample_rate
    
    if boc_type == 'sin':
        subcarrier = np.sign(np.sin(2 * np.pi * f_s * t))
    else:  # cos
        subcarrier = np.sign(np.cos(2 * np.pi * f_s * t))
    
    # 3. 扩频序列与子载波相乘
    s_boc = spread_upsampled * subcarrier
    
    return s_boc


def autocorrelation(x, max_lag=None):
    """计算自相关函数"""
    n = len(x)
    if max_lag is None:
        max_lag = n // 2
    
    result = np.zeros(2 * max_lag + 1)
    lags = np.arange(-max_lag, max_lag + 1)
    
    for i, lag in enumerate(lags):
        if lag == 0:
            result[i] = np.sum(x * x)
        elif lag > 0:
            result[i] = np.sum(x[lag:] * x[:-lag])
        else:
            result[i] = np.sum(x[:lag] * x[-lag:])
    
    result /= n  # 归一化
    return lags, result
```

## ⚠️ 注意事项

1. **规范性文件**：实际实现必须严格遵循各系统的**接口控制文件（ICD）**，其中明确定义了码生成多项式、调制细节和电文格式。

2. **BOC模糊问题**：BOC调制提供了更好的性能，但也带来了**模糊性**。接收机需要更复杂的算法（如Bump-Jump、Double Estimator、ASPeCT等）来锁定主峰。

3. **互相关特性**：不同的PRN码设计旨在减少卫星信号间的互干扰。强信号对弱信号的互相关干扰是远近效应的原因之一。

4. **恒包络要求**：星上发射机功放通常工作在饱和区，因此最终发射的信号必须是**恒包络**的。AltBOC、CASM、Interplex等多路复用技术就是为了在复用多个信号时保持恒包络。

5. **带宽限制**：仿真和实际系统中，信号在发射前都会经过**带宽限制滤波**，以符合频谱掩膜要求，这会影响相关函数的形状（使相关峰变圆）。

6. **极化方式**：GNSS信号通常采用右旋圆极化（RHCP），经过反射后极化特性会改变，这对多径建模和天线设计很重要。

7. **信号功率**：不同信号分量的功率分配不同，通常导频通道功率略高于数据通道（因为导频用于跟踪，需要更高的信噪比）。

8. **仿真中的量化效应**：数字信号仿真中，采样率和量化位数会影响仿真精度，需要根据应用需求合理选择。
