## 🎯 概述

**信号捕获（Acquisition）** 是GNSS接收机信号处理的第一步，其任务是从接收到的信号中检测出特定卫星的信号，并粗略估计其码相位和多普勒频移。

捕获是接收机"冷启动"时最耗时的环节，直接决定了**首次定位时间（TTFF）**。

捕获的本质是一个**二维搜索问题**：
- **码相位维**：搜索PRN码的起始位置（0-1022码片 for C/A码）
- **多普勒维**：搜索信号的载波频率偏移（±10kHz for GPS L1）

---

## 🔍 捕获的基本原理

### 捕获的目标

对于每颗待搜索的卫星，捕获需要回答三个问题：

1. **存在性**：这颗卫星的信号是否存在？
2. **码相位**：如果存在，PRN码的初始相位是多少？
3. **多普勒频移**：信号的载波频率偏移是多少？

捕获成功后，将粗略的码相位和多普勒估计值传递给**跟踪环路**进行精确跟踪。

### 二维搜索空间

捕获需要在二维空间中进行搜索：

| 维度 | 搜索范围 | 步长 | 典型搜索单元数 |
| :--- | :--- | :--- | :--- |
| **码相位** | 0 - 1022 码片（C/A码） | 0.5 码片 | ~2046 |
| **多普勒频移** | ±10 kHz（地面静态） | 500 Hz | ~41 |

总计搜索单元数：2046 × 41 ≈ 84,000 / 每颗卫星

对于32颗GPS卫星，总搜索单元约为 270 万个。

### 捕获判决准则

对于每个搜索单元，计算相关值并与门限比较：

$$
\text{判决：} \quad \max(R) \begin{cases}
> V_t & \text{捕获成功} \\
\leq V_t & \text{未捕获}
\end{cases}
$$

其中 $V_t$ 为检测门限。

**常用判决准则**：

1. **最大峰值法**：取搜索空间中的最大相关值与门限比较
2. **峰均比法**：最大峰值与平均值的比值
3. **峰次比法**：最大峰值与次大峰值的比值
4. **双重驻留法**：第一次粗检，第二次精检（降低虚警率）

**性能指标**：
- **检测概率 $P_d$**：信号存在时正确检测的概率
- **虚警概率 $P_{fa}$**：信号不存在时误判为存在的概率

## 📐 串行搜索捕获

### 基本原理

**串行搜索（Serial Search）** 是最简单的捕获方法：

1. 固定一个多普勒频率
2. 依次搜索每个码相位（移位本地码）
3. 计算相关值并与门限比较
4. 如果找到峰值，则捕获成功
5. 否则，切换到下一个多普勒频率，重复搜索

### 算法流程

```
对于每个多普勒频率 f_d:
    生成本地载波 NCO = cos(2π f_d t), sin(2π f_d t)
    对于每个码相位 τ:
        生成本地PRN码（移位τ）
        输入信号与本地载波相乘（下变频）→ I, Q
        I, Q 与本地PRN码相关
        计算相关值幅度 R = √(I_corr² + Q_corr²)
        如果 R > 门限:
            返回捕获成功，记录 τ 和 f_d
```

### 性能分析

**优点**：
- 实现简单，硬件资源占用少
- 易于理解和调试

**缺点**：
- 搜索速度慢，计算量大
- 对于软件接收机来说，实时性差

**平均搜索时间**：

$$
\bar{T}_{acq} = \frac{2 - P_d}{2 P_d} \cdot N_{cells} \cdot T_{dwell}
$$

其中：
- $N_{cells}$：搜索单元总数
- $T_{dwell}$：每个单元的驻留时间
- $P_d$：检测概率

## ⚡ 并行频率搜索

**并行频率搜索（Parallel Frequency Search）** 将频率维的搜索并行化：

1. 固定一个码相位
2. 对下变频后的信号做FFT，得到频谱
3. 在频谱上搜索信号峰值（对应多普勒频移）
4. 如果找到，则捕获成功
5. 否则，移到下一个码相位

**原理**：
- 码相位维度仍然串行搜索
- 频率维度通过FFT一次完成
- 搜索速度提升约为频率单元数倍

## 🚀 基于FFT的快速捕获

### 循环相关原理

两个序列的**循环相关**可以通过FFT高效计算：

$$
x[n] \circledast y[n] = \text{IFFT}\left( \text{FFT}(x[n]) \cdot \text{FFT}(y[n])^* \right)
$$

其中 $^*$ 表示复共轭。

对于GNSS信号捕获：
- $x[n]$：输入的数字中频信号（已下变频到基带）
- $y[n]$：本地PRN码序列

一次FFT运算即可得到**所有码相位**的相关值！

### FFT快速捕获算法

#### 并行码相位法（Parallel Code Phase Search）

**算法步骤**：

```
对于每个多普勒频率 f_d:
    1. 下变频：将输入信号与本地载波相乘，得到基带复信号
       s_I = x * cos(2π f_d t)
       s_Q = x * sin(2π f_d t)
       s_bb = s_I + j * s_Q
    
    2. 对基带信号做FFT
       S = FFT(s_bb)
    
    3. 生成本地PRN码（复信号，虚部为0），做FFT并取共轭
       C = FFT(prn_code)
       C_conj = conj(C)
    
    4. 频域相乘（对应时域相关）
       R = S * C_conj
    
    5. 逆FFT得到所有码相位的相关值
       r = IFFT(R)
    
    6. 取模值，搜索峰值
       peaks = abs(r)
       max_peak = max(peaks)
    
    7. 与门限比较
       如果 max_peak > V_t:
           捕获成功，码相位 = 峰值位置索引
```

**关键优势**：
- 码相位维度一次完成搜索
- 速度提升约1000倍（相比串行搜索）
- 是软件接收机的标准捕获算法

### 计算复杂度对比

假设：
- 码长 N = 1023
- 频率单元数 M = 41
- 每次相关运算 O(N)

| 算法 | 复杂度 / 每颗星 | 相对速度 |
| :--- | :--- | :--- |
| **串行搜索** | O(N × M × N) = O(N²M) | 1x（基准） |
| **并行频率** | O(N × N × log(N)) | ~10x |
| **并行码相位（FFT）** | O(M × N × log(N)) | ~100x |

## 📊 半比特法与全比特法

由于导航电文数据位（50bps，20ms/bit）的存在，积分时间不能超过一个数据比特周期，否则数据跳变会导致相关峰值下降。

### 半比特法（Half-bit Method）

- 积分时间 = 10 ms（半个数据位）
- 保证积分区间内没有数据跳变
- 积分时间短，灵敏度较低
- 适用于强信号环境

### 全比特法（Full-bit Method）

- 积分时间 = 20 ms（一个完整数据位）
- 需要知道数据比特的边沿位置
- 通常先做半比特捕获，找到比特边沿后再做全比特
- 积分时间长，灵敏度高

### 长积分（Coherent + Non-coherent）

为了提高捕获灵敏度，可以进行长时间积分：

1. **相干积分**：多个1ms/20ms的相关结果相干叠加
2. **非相干积分**：取模后平方相加（避免相位影响）

$$
R_{total} = \sum_{k=1}^{K} \left| R_k \right|^2
$$

其中 $K$ 为非相干积分次数。

## 🧪 BOC信号捕获

### BOC信号捕获的挑战

BOC（Binary Offset Carrier）信号的自相关函数具有**多峰特性**：
- 主峰位于0延迟处
- 边峰位于 ±n×T_s 处
- 主峰和边峰的幅度相近（BOC(1,1)边峰约为主峰的70%）

捕获时可能锁定到边峰，导致码相位偏差（通常为0.5码片）。

### 峰值跳跃法（Bump-Jump）

1. 正常捕获，找到相关峰位置
2. 在峰值左右各探测一个BOC子载波周期处的相关值
3. 根据左右"肩"的高度判断是否锁定在主峰
4. 如果锁定在边峰，则跳到主峰位置

### 双边带法

将BOC信号看作两个边带的BPSK信号：
- 上边带：$f_c + f_s$
- 下边带：$f_c - f_s$

分别捕获两个边带，然后组合结果，消除模糊度。

### ASK法（Autocorrelation Side-peak Cancellation）

通过对BOC信号和其相位偏移版本的相关函数做差，消除边峰。

## 💻 代码实现示例

### Python FFT快速捕获实现

```python
import numpy as np
from scipy.fft import fft, ifft


def generate_ca_code(prn, length=1023):
    """
    生成GPS C/A码（简化版，实际应根据ICD生成）
    
    这里用m序列近似模拟，实际需按GPS ICD的G2初始相位生成
    """
    # G1多项式: x^10 + x^3 + 1
    # G2多项式: x^10 + x^9 + x^8 + x^6 + x^3 + x^2 + 1
    # 简化：用随机序列代替
    np.random.seed(prn)
    code = np.random.choice([-1, 1], size=length)
    return code


def fft_acquisition(signal, prn_code, fs, doppler_range, doppler_step, 
                    integration_time=1e-3, threshold=None):
    """
    基于FFT的并行码相位捕获算法
    
    参数:
        signal: 输入的中频信号 (实信号) [samples]
        prn_code: 本地PRN码序列 (值为±1)
        fs: 采样率 [Hz]
        doppler_range: 多普勒搜索范围 [Hz], (min, max)
        doppler_step: 多普勒搜索步长 [Hz]
        integration_time: 积分时间 [s]
        threshold: 检测门限，None则自动估计
    
    返回:
        success: 是否捕获成功
        code_phase: 码相位估计 [samples]
        doppler: 多普勒估计 [Hz]
        peak_value: 峰值相关值
    """
    N = int(fs * integration_time)  # 积分点数
    N_code = len(prn_code)
    
    # 生成本地码的过采样版本
    samples_per_chip = int(fs / 1.023e6)
    # 确保长度为N
    code_upsampled = np.repeat(prn_code, samples_per_chip)[:N]
    
    # 本地码FFT（预计算）
    code_fft = fft(code_upsampled)
    code_fft_conj = np.conj(code_fft)
    
    # 生成频率列表
    doppler_freqs = np.arange(doppler_range[0], doppler_range[1] + doppler_step, doppler_step)
    
    # 取一段信号
    sig = signal[:N]
    
    best_peak = 0
    best_doppler = 0
    best_phase = 0
    
    # 遍历每个多普勒频率
    for fd in doppler_freqs:
        # 1. 下变频（载波剥离）
        t = np.arange(N) / fs
        carrier_i = np.cos(2 * np.pi * fd * t)
        carrier_q = np.sin(2 * np.pi * fd * t)
        
        # 复基带信号
        s_bb = sig * (carrier_i - 1j * carrier_q)
        
        # 2. FFT
        sig_fft = fft(s_bb)
        
        # 3. 频域相乘 = 时域相关
        corr_fft = sig_fft * code_fft_conj
        
        # 4. IFFT得到相关结果
        corr = ifft(corr_fft)
        
        # 5. 取模找峰值
        corr_mag = np.abs(corr)
        peak_idx = np.argmax(corr_mag)
        peak_val = corr_mag[peak_idx]
        
        if peak_val > best_peak:
            best_peak = peak_val
            best_doppler = fd
            best_phase = peak_idx
    
    # 6. 门限判决
    if threshold is None:
        # 自适应门限：基于噪声标准差
        # 峰值应远大于噪声底
        noise_floor = np.mean(np.abs(ifft(sig_fft * code_fft_conj)))
        threshold = 3.0 * noise_floor  # 3-sigma准则
    
    success = best_peak > threshold
    
    return success, best_phase, best_doppler, best_peak


def serial_acquisition(signal, prn_code, fs, doppler_range, doppler_step,
                       integration_time=1e-3, threshold=None):
    """
    串行搜索捕获（用于对比）
    """
    N = int(fs * integration_time)
    N_code = len(prn_code)
    samples_per_chip = int(fs / 1.023e6)
    
    sig = signal[:N]
    doppler_freqs = np.arange(doppler_range[0], doppler_range[1] + doppler_step, doppler_step)
    
    best_peak = 0
    best_doppler = 0
    best_phase = 0
    
    t = np.arange(N) / fs
    
    for fd in doppler_freqs:
        # 下变频
        carrier_i = np.cos(2 * np.pi * fd * t)
        carrier_q = np.sin(2 * np.pi * fd * t)
        s_i = sig * carrier_i
        s_q = sig * carrier_q
        
        # 串行搜索每个码相位（步长为0.5码片）
        for phase_samples in range(0, N_code * samples_per_chip, samples_per_chip // 2):
            # 生成移位后的本地码
            code_shifted = np.roll(np.repeat(prn_code, samples_per_chip)[:N], phase_samples)
            
            # 相关
            i_corr = np.sum(s_i * code_shifted)
            q_corr = np.sum(s_q * code_shifted)
            corr_mag = np.sqrt(i_corr**2 + q_corr**2)
            
            if corr_mag > best_peak:
                best_peak = corr_mag
                best_doppler = fd
                best_phase = phase_samples
    
    if threshold is None:
        threshold = best_peak * 0.5  # 简化
    
    success = best_peak > threshold
    
    return success, best_phase, best_doppler, best_peak


# 使用示例
if __name__ == "__main__":
    # 参数设置
    fs = 4.092e6  # 采样率 4.092 MHz (4倍C/A码速率)
    prn = 1       # 卫星PRN号
    true_doppler = 2500  # 真实多普勒频移 Hz
    true_phase = 100     # 真实码相位 samples
    
    # 生成本地码
    ca_code = generate_ca_code(prn)
    
    # 生成模拟接收信号
    N = int(fs * 1e-3)  # 1ms数据
    t = np.arange(N) / fs
    
    # 过采样并移位
    samples_per_chip = int(fs / 1.023e6)
    code_tx = np.roll(np.repeat(ca_code, samples_per_chip)[:N], true_phase)
    
    # 调制到中频（假设中频为0，即基带）
    # 添加载波和多普勒
    signal = code_tx * np.cos(2 * np.pi * true_doppler * t)
    
    # 添加噪声
    noise_power = 0.5
    signal += noise_power * np.random.randn(N)
    
    print(f"生成模拟信号: PRN={prn}, 多普勒={true_doppler}Hz, 相位={true_phase}采样点")
    
    # FFT捕获
    success, est_phase, est_doppler, peak = fft_acquisition(
        signal, ca_code, fs,
        doppler_range=(-5000, 5000),
        doppler_step=500,
        integration_time=1e-3
    )
    
    print(f"\nFFT捕获结果:")
    print(f"  捕获成功: {success}")
    print(f"  估计码相位: {est_phase} 采样点 (真实: {true_phase})")
    print(f"  估计多普勒: {est_doppler} Hz (真实: {true_doppler})")
    print(f"  峰值: {peak:.3f}")
    
    # 计算码相位误差（码片）
    phase_error_chips = abs(est_phase - true_phase) / samples_per_chip
    print(f"  码相位误差: {phase_error_chips:.3f} 码片")
```

## ⚠️ 注意事项

1. **采样率选择**：采样率应是码速率的整数倍，便于码片对齐，通常取2x、4x、8x等。

2. **多普勒搜索步长**：步长过大会漏掉信号，过小则搜索慢。通常取1/(2×积分时间)。

3. **积分时间**：
   - 积分时间越长，灵敏度越高
   - 但受数据比特跳变限制（最长20ms for 50bps）
   - 长积分需考虑数据比特同步

4. **门限设置**：
   - 门限过高：漏检（检测概率低）
   - 门限过低：虚警（误捕概率高）
   - 通常使用恒虚警率（CFAR）准则

5. **信号功率估计**：捕获前通常不知道信号强度，自适应门限很重要。

6. **多星并行捕获**：现代接收机通常同时搜索多颗卫星，需要合理分配计算资源。

7. **弱信号捕获**：
   - 增加积分时间（相干+非相干）
   - 使用更灵敏的检测算法
   - 辅助信息（如历书、粗时间）可缩小搜索范围

8. **BOC信号捕获**：注意边峰模糊问题，捕获后需要验证是否锁定在主峰。

9. **硬件实现**：
   - FPGA中常用匹配滤波器（匹配滤波器 = 串行相关的硬件加速）
   - 或FFT引擎实现并行码相位搜索
