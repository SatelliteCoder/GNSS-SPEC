## 🎯 概述

**对流层（Troposphere）** 是地球大气的最低层，高度约0-50 km。与电离层不同，对流层是**非色散介质**，对不同频率的电磁波延迟相同，因此**无法通过双频观测消除**。

对流层延迟的特点：
- 天顶方向约 **2.3 米**（干分量约2.0米，湿分量约0.3米）
- 低仰角时（5°）可达 **20-25 米**
- 干分量占总延迟的 90% 左右，可通过地面气象参数精确估计
- 湿分量变化大，难以精确估计，是对流层延迟误差的主要来源

## 🌬️ 对流层物理基础

### 对流层结构

| 层 | 高度范围 | 特点 |
| :--- | :--- | :--- |
| **对流层** | 0 - 12 km | 温度随高度递减，天气现象主要发生于此 |
| **平流层** | 12 - 50 km | 温度随高度递增（臭氧吸收紫外线） |
| **中间层** | 50 - 85 km | 温度随高度递减 |

对于GNSS信号，对流层延迟主要来自对流层和平流层（0-50 km）。

### 大气折射

电磁波在大气中传播时，由于空气密度随高度变化，传播路径会发生弯曲，导致传播路径长度大于几何距离。

**折射率（Refractivity）** 定义为：

$$
N = (n - 1) \times 10^6
$$

其中 $n$ 为折射率。

根据理想气体定律，大气折射率可表示为：

$$
N = k_1 \frac{P_d}{T} + k_2 \frac{P_v}{T} + k_3 \frac{P_v}{T^2}
$$

其中：
- $P_d$：干空气气压（hPa）
- $P_v$：水汽压（hPa）
- $T$：温度（K）
- $k_1, k_2, k_3$：经验常数

通常将折射率分为**干分量**和**湿分量**两部分：

$$
N = N_d + N_w
$$

- 干分量 $N_d$：由干空气引起，约占 90%
- 湿分量 $N_w$：由水汽引起，约占 10%，但变化剧烈

## 📐 对流层延迟数学模型

### 天顶延迟

天顶方向的对流层延迟（信号从头顶正上方穿过大气）：

$$
ZTD = ZHD + ZWD
$$

其中：
- **ZHD（Zenith Hydrostatic Delay）**：天顶流体静力学延迟（干延迟）
- **ZWD（Zenith Wet Delay）**：天顶湿延迟

**ZHD 的计算**：

$$
ZHD = \frac{10^{-6} k_1 R_d}{g_m} P_0
$$

简化为：

$$
ZHD = 2.2768 \times 10^{-3} \cdot P_0
$$

其中 $P_0$ 为测站地面气压（hPa）。ZHD 的估计精度可达毫米级。

**ZWD 的计算**：

$$
ZWD = 10^{-6} \int_{z_0}^{\infty} \left( k_2' \frac{P_v}{T} + k_3 \frac{P_v}{T^2} \right) dz
$$

湿延迟难以精确估计，因为水汽分布变化剧烈。

### 投影函数（映射函数）

对于非天顶方向的卫星，对流层延迟需要乘以投影函数（Mapping Function）：

$$
T = ZHD \cdot m_h(E) + ZWD \cdot m_w(E)
$$

其中 $E$ 为卫星仰角，$m_h(E)$ 和 $m_w(E)$ 分别为干、湿分量的投影函数。

**简化投影函数（secant近似）**：

$$
m(E) = \frac{1}{\sin(E)}
$$

这是最简单的近似，在高仰角时效果尚可，但低仰角时误差较大。

## 📊 Saastamoinen 模型

**Saastamoinen 模型**是最经典的对流层延迟模型之一，直接使用地面气象参数计算总延迟。

### 计算公式

$$
T = \frac{0.0022768 \cdot P}{\sin(E + \frac{3.086}{E + 0.0167})} + \frac{0.0022768 \cdot (1255/T + 0.05) \cdot e}{\sin(E + \frac{2.248}{E + 0.0364})}
$$

其中：
- $P$：地面气压（hPa）
- $T$：地面温度（K）
- $e$：水汽压（hPa）
- $E$：卫星仰角（度）

### 天顶延迟形式

天顶方向（E = 90°）时：

$$
ZHD = 0.0022768 \cdot P \cdot f(h, \phi)
$$

$$
ZWD = 0.0022768 \cdot \left( \frac{1255}{T} + 0.05 \right) \cdot e
$$

其中 $f(h, \phi)$ 为高度和纬度修正因子。

### 水汽压计算

水汽压 $e$ 可通过相对湿度 RH 和温度 T 计算：

$$
e_s = 6.108 \cdot \exp\left( \frac{17.15 T - 4684}{T - 38.45} \right)
$$

$$
e = e_s \cdot \frac{RH}{100}
$$

其中 $e_s$ 为饱和水汽压，$T$ 单位为摄氏度。

## 🏔️ Hopfield 模型

**Hopfield 模型**假设大气折射率随高度呈四次方递减：

### 干分量

$$
N_d(h) = N_{d0} \left( \frac{h_d - h}{h_d} \right)^4
$$

$$
ZHD = \frac{10^{-6} N_{d0} h_d}{5}
$$

其中：
- $N_{d0}$：地面干折射率
- $h_d$：干大气高度（约 40 km）

### 湿分量

$$
N_w(h) = N_{w0} \left( \frac{h_w - h}{h_w} \right)^4
$$

$$
ZWD = \frac{10^{-6} N_{w0} h_w}{5}
$$

其中：
- $N_{w0}$：地面湿折射率
- $h_w$：湿大气高度（约 12 km）

### 投影函数

Hopfield模型的投影函数通过数值积分得到，形式较为复杂。

---

## 🌧️ UNB3 模型

**UNB3 模型**（University of New Brunswick 模型）是一种无需实时气象数据的对流层模型：

- 基于全球平均气象数据
- 输入：位置（经纬度、高度）、一年中的天数
- 输出：天顶延迟和投影函数参数
- 被广泛用于GPS广域增强系统（WAAS）

UNB3 模型使用 5°×5° 网格的气象数据，通过插值得到测站位置的气象参数。

## 📐 GMF/VMF 映射函数

### GMF（Global Mapping Function）

**GMF** 是基于全球气象数据的投影函数模型：

- 干、湿分量分别建模
- 系数按月和经纬度网格提供
- 精度优于 Niell 投影函数
- 适用于全球范围

GMF 的形式：

$$
m(E) = \frac{1 + \frac{a}{1 + \frac{b}{1 + c}}}{\sin(E) + \frac{a}{\sin(E) + \frac{b}{\sin(E) + c}}}
$$

其中 $a, b, c$ 为与位置和季节相关的系数。

### VMF（Vienna Mapping Function）

**VMF** 是目前精度最高的投影函数之一：

- **VMF1**：基于数值天气预报数据，需要定期更新系数
- **VMF3**：最新版本，精度更高
- 被 IGS（国际GNSS服务）推荐使用
- 对于高精度GNSS应用（如PPP、VLBI）必不可少

## 💻 代码实现示例

### Python 实现 Saastamoinen 模型

```python
import math


def saastamoinen_tropo_delay(pressure, temperature_c, humidity, elevation_deg):
    """
    Saastamoinen对流层延迟模型
    
    参数:
        pressure: 地面气压 [hPa]
        temperature_c: 地面温度 [摄氏度]
        humidity: 相对湿度 [%]
        elevation_deg: 卫星仰角 [度]
    
    返回:
        tropo_delay: 对流层总延迟 [m]
        zhd: 天顶干延迟 [m]
        zwd: 天顶湿延迟 [m]
    """
    # 温度转换为开尔文
    T = temperature_c + 273.15
    
    # 计算饱和水汽压 (Magnus公式)
    e_s = 6.108 * math.exp((17.15 * temperature_c - 4684) / (temperature_c - 38.45))
    
    # 计算水汽压
    e = e_s * humidity / 100.0
    
    # 仰角转换为弧度
    E = math.radians(elevation_deg)
    
    # Saastamoinen 模型
    # 干分量
    dry_num = 0.0022768 * pressure
    dry_den = math.sin(E + math.radians(3.086 / (elevation_deg + 0.0167)))
    dry_delay = dry_num / dry_den
    
    # 湿分量
    wet_num = 0.0022768 * (1255.0 / T + 0.05) * e
    wet_den = math.sin(E + math.radians(2.248 / (elevation_deg + 0.0364)))
    wet_delay = wet_num / wet_den
    
    # 总延迟
    tropo_delay = dry_delay + wet_delay
    
    # 天顶延迟（用于参考）
    zhd = 0.0022768 * pressure
    zwd = 0.0022768 * (1255.0 / T + 0.05) * e
    
    return tropo_delay, zhd, zwd


def hopfield_tropo_delay(pressure, temperature_c, humidity, height, elevation_deg):
    """
    Hopfield对流层延迟模型（简化版）
    
    参数:
        pressure: 地面气压 [hPa]
        temperature_c: 地面温度 [摄氏度]
        humidity: 相对湿度 [%]
        height: 测站高度 [m]
        elevation_deg: 卫星仰角 [度]
    
    返回:
        tropo_delay: 对流层总延迟 [m]
    """
    T = temperature_c + 273.15
    e_s = 6.108 * math.exp((17.15 * temperature_c - 4684) / (temperature_c - 38.45))
    e = e_s * humidity / 100.0
    
    # 地面折射率
    N_d = 77.6 * pressure / T
    N_w = (72.0 * e / T) + (0.3739e4 * e / (T ** 2))
    
    # 大气顶高度
    h_d = 40136.0 + 148.72 * (T - 273.16)  # 干大气顶高度
    h_w = 11000.0                           # 湿大气顶高度
    
    E = math.radians(elevation_deg)
    sin_E = math.sin(E)
    
    # 地球半径
    R = 6378137.0
    
    # 计算天顶延迟
    zhd = 1e-6 * N_d * h_d / 5.0
    zwd = 1e-6 * N_w * h_w / 5.0
    
    # 投影函数（简化，使用数值积分近似）
    # 这里使用简化的映射函数
    def mapping_function(E, h_top):
        """简化的投影函数"""
        sin_E = math.sin(E)
        # 使用近似公式
        return 1.0 / (sin_E + 0.00143 / (math.tan(E) + 0.0445))
    
    m_h = mapping_function(E, h_d)
    m_w = mapping_function(E, h_w)
    
    tropo_delay = zhd * m_h + zwd * m_w
    
    return tropo_delay, zhd, zwd


def compute_slant_delay(zhd, zwd, elevation_deg, model='simple'):
    """
    根据天顶延迟和仰角计算斜路径延迟
    
    参数:
        zhd: 天顶干延迟 [m]
        zwd: 天顶湿延迟 [m]
        elevation_deg: 卫星仰角 [度]
        model: 投影函数模型 ('simple', 'niell')
    
    返回:
        slant_delay: 斜路径对流层延迟 [m]
    """
    E = math.radians(elevation_deg)
    
    if model == 'simple':
        # 简化投影函数
        m = 1.0 / math.sin(E)
        slant_delay = (zhd + zwd) * m
    
    elif model == 'niell':
        # Niell投影函数（简化版）
        sin_E = math.sin(E)
        
        # 干分量映射函数系数（纬度相关，此处用中纬度近似）
        a_h, b_h, c_h = 0.0012769, 0.0022224, 0.0001283
        a_w, b_w, c_w = 0.0005802, 0.0014277, 0.0000786
        
        def mf(sin_E, a, b, c):
            return (1 + a/(1 + b/(1 + c))) / (sin_E + a/(sin_E + b/(sin_E + c)))
        
        m_h = mf(sin_E, a_h, b_h, c_h)
        m_w = mf(sin_E, a_w, b_w, c_w)
        
        slant_delay = zhd * m_h + zwd * m_w
    
    else:
        raise ValueError(f"Unknown model: {model}")
    
    return slant_delay


# 使用示例
if __name__ == "__main__":
    # 典型气象条件
    pressure = 1013.25  # hPa (标准大气压)
    temperature = 20.0   # 摄氏度
    humidity = 60.0      # 相对湿度 %
    
    # 不同仰角下的对流层延迟
    elevations = [5, 10, 15, 30, 45, 60, 90]
    
    print("仰角(°) | 总延迟(m) | 干延迟(m) | 湿延迟(m)")
    print("-" * 50)
    
    for elev in elevations:
        delay, zhd, zwd = saastamoinen_tropo_delay(
            pressure, temperature, humidity, elev
        )
        print(f"{elev:7d} | {delay:9.3f} | {zhd:9.3f} | {zwd:9.3f}")
    
    # 对比天顶延迟
    print(f"\n天顶干延迟 (ZHD): {zhd:.3f} m")
    print(f"天顶湿延迟 (ZWD): {zwd:.3f} m")
    print(f"天顶总延迟 (ZTD): {zhd + zwd:.3f} m")
```

## ⚠️ 注意事项

1. **频率无关**：对流层延迟与信号频率无关，双频接收机无法消除对流层延迟。

2. **干/湿分离**：干延迟可精确估计（误差cm级），湿延迟是主要误差源（误差cm-dm级）。

3. **低仰角误差**：投影函数在低仰角时误差增大，5°仰角时投影函数误差可达数米。

4. **气象数据**：Saastamoinen等模型需要实时气象数据，否则精度下降。

5. **模型选择**：
   - 一般应用：Saastamoinen + 简单投影函数
   - 高精度应用：VMF + 实时气象数据
   - 无气象数据：UNB3 / GPT2 模型

6. **高度修正**：测站海拔较高时，需要对标准海平面模型进行高度修正。

7. **水平梯度**：在复杂地形或天气条件下，对流层存在水平梯度，需要额外建模。

8. **仿真建议**：在GNSS信号仿真中，对流层延迟通常作为确定性误差加入，可根据仿真精度要求选择合适的模型。
