## 🎯 概述

**电离层（Ionosphere）** 是地球大气的一个电离区域，高度约在60-1000 km之间。由于受到太阳高能辐射的作用，大气分子被电离，产生大量的自由电子和离子。

电离层对GNSS信号的传播有显著影响：
- **群延迟（Group Delay）**：伪距测量值偏大
- **相位超前（Phase Advance）**：载波相位测量值偏小

电离层延迟是GNSS定位中最大的误差源之一，天顶方向可达**几米到几十米**，低仰角时甚至超过100米。

---

## ⚛️ 电离层物理基础

### 电离层结构

电离层根据电子密度分布可分为几层：

| 层 | 高度范围 | 特点 |
| :--- | :--- | :--- |
| **D层** | 60 - 90 km | 白天存在，夜间消失 |
| **E层** | 90 - 150 km | 中等电子密度，受太阳活动影响 |
| **F1层** | 150 - 200 km | 白天存在，夏季明显 |
| **F2层** | 200 - 1000 km | 电子密度最高，是电离层延迟的主要来源 |

电子密度峰值通常出现在约 300-400 km 高度，称为 **F2层峰值（hmF2）**。

### 电离层对GNSS信号的影响

电离层是**色散介质**，其折射率与信号频率有关：

$$
n = \sqrt{1 - \frac{Ne^2}{4\pi^2 \varepsilon_0 m f^2}}
$$

其中：
- $N$：电子密度（电子数/m³）
- $e$：电子电荷（1.602×10⁻¹⁹ C）
- $m$：电子质量（9.109×10⁻³¹ kg）
- $\varepsilon_0$：真空介电常数
- $f$：信号频率

由于 GNSS 信号频率很高（L1 ≈ 1.5 GHz），折射率非常接近1，可近似为：

$$
n \approx 1 - \frac{40.3 \cdot N}{f^2}
$$

## 📐 电离层延迟数学模型

### 群延迟与相位超前

电离层延迟沿信号传播路径积分计算：

**伪距（群）延迟**：

$$
I_g = \int_s (n_g - 1) ds = \frac{40.3}{f^2} \int_s N ds = \frac{40.3}{f^2} \cdot TEC
$$

**载波相位延迟（超前）**：

$$
I_p = \int_s (n_p - 1) ds = -\frac{40.3}{f^2} \cdot TEC
$$

其中：
- $TEC$：总电子含量（Total Electron Content），单位为 TECU（1 TECU = 10¹⁶ 电子/m²）
- $f$：信号频率（Hz）

**关键性质**：
1. 电离层延迟与频率平方成反比 → **双频接收机可消除一阶电离层延迟**
2. 群延迟与相位延迟大小相等、符号相反
3. 一阶项约占总电离层延迟的 99.5%

### Appleton-Hartree 公式

更精确的电离层折射率公式（考虑地磁场影响）：

$$
n^2 = 1 - \frac{X}{1 - jZ - \frac{Y_T^2}{2(1-X-jZ)} \pm \sqrt{\frac{Y_T^4}{4(1-X-jZ)^2} + Y_L^2}}
$$

其中：
- $X = f_N^2 / f^2$，$f_N$ 为等离子体频率
- $Y = f_H / f$，$f_H$ 为电子回旋频率
- $Y_T, Y_L$：地磁场的横向和纵向分量
- $Z = \nu / f$，$\nu$ 为碰撞频率

对于 GNSS 频率，通常只考虑一阶近似即可满足精度要求。

## 📊 Klobuchar 模型

**Klobuchar 模型**是GPS系统使用的电离层修正模型，通过导航电文广播8个模型参数，用户可自行计算电离层延迟。

### 模型原理

Klobuchar 模型是一个**经验模型**，将电离层天顶延迟建模为当地时间的余弦函数：

$$
I_{iono, z} = \begin{cases}
5 \times 10^{-9} + A \cos\left(\frac{2\pi (t - 50400)}{P}\right), & \text{白天} \\
5 \times 10^{-9}, & \text{夜间}
\end{cases}
$$

（单位：秒，转换为米需乘以光速）

### 计算公式

完整的Klobuchar模型计算步骤如下：

**步骤1：计算电离层穿刺点（IPP）**

信号传播路径与电离层薄壳（通常取高度350-400km）的交点称为电离层穿刺点。

$$
\psi' = \frac{0.0137}{E + 0.11} - 0.022 \quad \text{(地心角，半周)}
$$

穿刺点纬度：
$$
\phi_i = \phi_u + \psi' \cdot \cos(A)
$$

穿刺点经度：
$$
\lambda_i = \lambda_u + \frac{\psi' \cdot \sin(A)}{\cos(\phi_i)}
$$

其中：
- $E$：卫星仰角（半周）
- $A$：卫星方位角（半周）
- $\phi_u, \lambda_u$：用户纬度、经度（半周）

**步骤2：计算当地时间**

$$
t = 43200 \cdot \lambda_i + t_{GPS} \quad (\text{秒})
$$

（对86400取模）

**步骤3：计算倾斜因子（投影函数）**

$$
F = 1 + 16 \cdot (0.53 - E)^3
$$

其中 $E$ 为仰角（半周）。

**步骤4：计算振幅和周期**

$$
A_{iono} = \sum_{n=0}^{3} \alpha_n \phi_m^n
$$

$$
P_{iono} = \sum_{n=0}^{3} \beta_n \phi_m^n
$$

其中 $\phi_m$ 为穿刺点的地磁纬度（半周），$\alpha_n, \beta_n$ 为广播的电离层参数。

**步骤5：计算电离层延迟**

$$
I = \begin{cases}
F \cdot \left[5 \times 10^{-9} + A_{iono} \cos\left(\frac{2\pi (t - 50400)}{P_{iono}}\right)\right], & |X| < \pi/2 \\
F \cdot 5 \times 10^{-9}, & \text{其他}
\end{cases}
$$

其中 $X = \frac{2\pi (t - 50400)}{P_{iono}}$。

最终结果乘以光速得到米级延迟。

### 参数说明

GPS广播的8个Klobuchar参数：
- `alpha0, alpha1, alpha2, alpha3`：振幅系数
- `beta0, beta1, beta2, beta3`：周期系数

这些参数由GPS控制段定期更新，有效期约24小时。

## 🧪 Bent 模型

**Bent 模型**是另一个广泛使用的电离层经验模型，比Klobuchar模型更精确：

- 基于全球12个扇区的电子密度剖面
- 考虑太阳活动指数（F10.7）
- 提供全天时的电离层延迟估计
- 精度约为 Klobuchar 模型的2倍

Bent 模型在航空和高精度应用中使用较多。

---

## 🌍 国际参考电离层 (IRI)

**IRI（International Reference Ionosphere）** 是国际空间委员会（COSPAR）和国际无线电科学联合会（URSI）联合推荐的电离层标准模型：

- 基于全球观测数据建立的经验模型
- 提供电子密度、温度、离子成分等参数的全球分布
- 输入参数：位置、时间、太阳活动指数、地磁指数
- 是目前最准确的电离层经验模型之一

IRI 模型常用于高精度GNSS应用和科学研究。

## 📡 双频电离层修正

对于双频（或多频）接收机，可以直接利用观测值消除电离层延迟的一阶项。

### 双频伪距电离层修正

$$
P_{iono-free} = \frac{f_1^2 P_1 - f_2^2 P_2}{f_1^2 - f_2^2}
$$

### 双频载波相位电离层修正

$$
L_{iono-free} = \frac{f_1^2 L_1 - f_2^2 L_2}{f_1^2 - f_2^2}
$$

其中 $f_1, f_2$ 为两个频率，$P_1, P_2$ 和 $L_1, L_2$ 分别为对应频率的伪距和载波相位观测值。

**注意**：双频修正只能消除一阶电离层延迟，高阶项（约0.1-1%）仍然存在。

## 💻 代码实现示例

### Python 实现 Klobuchar 模型

```python
import math

C = 299792458.0  # 光速 (m/s)


def klobuchar_iono_correction(t_gps, lat_u, lon_u, elevation, azimuth, alpha, beta):
    """
    Klobuchar电离层延迟模型
    
    参数:
        t_gps: GPS周内秒 [s]
        lat_u: 用户纬度 [半周] (纬度° / 180)
        lon_u: 用户经度 [半周] (经度° / 180)
        elevation: 卫星仰角 [半周]
        azimuth: 卫星方位角 [半周]
        alpha: 电离层alpha参数 [半周, 数组长度4]
        beta: 电离层beta参数 [半周, 数组长度4]
    
    返回:
        iono_delay: 电离层延迟 [m] (L1频率)
    """
    # --- 步骤1: 计算地心角 ---
    psi = 0.0137 / (elevation + 0.11) - 0.022  # 半周
    
    # --- 步骤2: 计算穿刺点纬度 ---
    phi_i = lat_u + psi * math.cos(azimuth * math.pi)
    
    # 限制纬度范围
    if phi_i > 0.416:
        phi_i = 0.416
    elif phi_i < -0.416:
        phi_i = -0.416
    
    # --- 步骤3: 计算穿刺点经度 ---
    lambda_i = lon_u + (psi * math.sin(azimuth * math.pi)) / math.cos(phi_i * math.pi)
    
    # --- 步骤4: 计算地磁纬度 ---
    phi_m = phi_i + 0.064 * math.cos((lambda_i - 1.617) * math.pi)  # 半周
    
    # --- 步骤5: 计算当地时间 ---
    t = 43200.0 * lambda_i + t_gps
    t = t % 86400.0  # 取模到 0-86400秒
    
    # --- 步骤6: 计算倾斜因子 ---
    f = 1.0 + 16.0 * math.pow(0.53 - elevation, 3)
    
    # --- 步骤7: 计算振幅和周期 ---
    A_iono = alpha[0] + alpha[1]*phi_m + alpha[2]*phi_m**2 + alpha[3]*phi_m**3
    if A_iono < 0:
        A_iono = 0
    
    P_iono = beta[0] + beta[1]*phi_m + beta[2]*phi_m**2 + beta[3]*phi_m**3
    if P_iono < 72000:
        P_iono = 72000
    
    # --- 步骤8: 计算电离层延迟 ---
    X = 2.0 * math.pi * (t - 50400.0) / P_iono
    
    if abs(X) < math.pi / 2:
        # 白天
        t_iono = f * (5e-9 + A_iono * math.cos(X))
    else:
        # 夜间
        t_iono = f * 5e-9
    
    # 转换为米（L1频率）
    iono_delay = t_iono * C
    
    return iono_delay


def dual_freq_iono_correction(P1, P2, f1, f2):
    """
    双频电离层修正（无电离层组合）
    
    参数:
        P1: L1频率伪距 [m]
        P2: L2频率伪距 [m]
        f1: L1频率 [Hz]
        f2: L2频率 [Hz]
    
    返回:
        P_if: 无电离层组合伪距 [m]
        iono_delay_L1: L1频率电离层延迟 [m]
    """
    # 无电离层组合
    P_if = (f1**2 * P1 - f2**2 * P2) / (f1**2 - f2**2)
    
    # 计算L1电离层延迟
    iono_delay_L1 = P1 - P_if
    
    return P_if, iono_delay_L1


def tec_to_delay(tec, frequency):
    """
    TEC转换为电离层延迟
    
    参数:
        tec: 总电子含量 [TECU]
        frequency: 信号频率 [Hz]
    
    返回:
        delay: 电离层群延迟 [m]
    """
    # 1 TECU = 10^16 electrons/m^2
    delay = 40.3 * tec * 1e16 / (frequency ** 2)
    return delay


# 使用示例
if __name__ == "__main__":
    # GPS L1 和 L2 频率
    f1 = 1575.42e6  # Hz
    f2 = 1227.60e6  # Hz
    
    # Klobuchar模型参数示例（GPS广播的典型值）
    alpha = [3.82e-8, 1.49e-8, -1.79e-7, 0.0]
    beta = [1.43e5, 0.0, -3.28e5, 1.13e5]
    
    # 计算电离层延迟
    delay = klobuchar_iono_correction(
        t_gps=3600*12,    # 中午12点
        lat_u=30/180,     # 北纬30度
        lon_u=116/180,    # 东经116度
        elevation=45/180, # 仰角45度
        azimuth=90/180,   # 方位角90度
        alpha=alpha,
        beta=beta
    )
    
    print(f"Klobuchar电离层延迟（L1，天顶等效）: {delay:.3f} m")
    
    # 双频修正示例
    P1 = 20000000.0 + 10.0  # L1伪距，含10米电离层延迟
    P2 = 20000000.0 + 10.0 * (f1/f2)**2  # L2伪距
    
    P_if, iono_L1 = dual_freq_iono_correction(P1, P2, f1, f2)
    print(f"无电离层组合伪距: {P_if:.3f} m")
    print(f"L1电离层延迟估计: {iono_L1:.3f} m")
```

## ⚠️ 注意事项

1. **模型精度**：Klobuchar模型只能修正约50-70%的电离层延迟，在太阳活动高峰期或低纬度地区误差更大。

2. **单位转换**：GPS导航电文中的角度参数以**半圆**为单位，使用时需注意转换。

3. **薄壳近似**：Klobuchar模型假设电离层电子集中在350-400km的薄壳上，这是一种近似。

4. **夜间模型**：Klobuchar模型的夜间值为常数（5ns），实际夜间电离层延迟可能更低。

5. **频率依赖**：电离层延迟与频率平方成反比，不同频率的信号延迟不同。

6. **闪烁效应**：在低纬度和高纬度地区，电离层可能出现快速波动（闪烁），静态模型无法捕捉。

7. **高阶项**：双频修正只能消除一阶项，高精度应用需考虑二阶、三阶项。

8. **仿真适用性**：在信号仿真中，如需高保真电离层建模，建议使用IRI模型或实测TEC数据。
